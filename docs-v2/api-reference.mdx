Runtime for Teams of independent AI agents.

Each Agent keeps its own harness, tools, and memory. A Team is a Runtime
object: discovery, messaging, and work tracking. Everyday names live
here: [`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent), [`Context`](/api/agent-context#agentconnect-agent-context-context), [`MailboxMessage`](/api/core-message#agentconnect-core-message-mailboxmessage), [`Team`](/api/team-runtime#agentconnect-team-runtime-team), [`Ticket`](/api/core-ticket#agentconnect-core-ticket-ticket),
[`AgentProfile`](/api/core-profile#agentconnect-core-profile-agentprofile), [`Skill`](/api/core-profile#agentconnect-core-profile-skill), [`AgentIdentity`](/api/core-identity#agentconnect-core-identity-agentidentity), and the public errors.

Import schema nouns from the defining [`agentconnect.core`](/api/core) module when
you need the full type. Session helpers live on [`agentconnect.agent`](/api/agent).
Hosting adapters live on [`agentconnect.team.http`](/api/team-http), [`agentconnect.team.store`](/api/team-store),
and [`agentconnect.team.directory`](/api/team-directory). Team MCP is [`agentconnect.mcp`](/api/mcp).

Agents can share this process with a started [`Team`](/api/team-runtime#agentconnect-team-runtime-team) (embedded join).
This process can also host Agents listed in a Team file (`agentconnect
up`). Independently deployed Agents join the served origin by URL and a
join token. [`Team.serve`](/api/team-runtime#agentconnect-team-runtime-team-serve) and `agentconnect up` bind loopback only;
authenticated or non-loopback HTTP uses
[`agentconnect.team.http.create_runtime_app`](/api/team-http#agentconnect-team-http-create-runtime-app). Memory storage does not
survive process exit.

A bounded `ask` can return an `open` Ticket. Read `content` only after
`state` is `completed`. Close each Session with `leave` before stopping
the Team.

**Examples:**

Two Agents in this process exchange a request and a reply:

```python
import asyncio

from agentconnect import BaseAgent, Context, MailboxMessage, Team

class Echo(BaseAgent):
    async def handle(self, msg: MailboxMessage, ctx: Context) -> dict | None:
        if msg.kind != "request":
            return None
        return {"echo": msg.content}

async def main() -> None:
    team = await Team("demo").start()
    echo = Echo(name="echo")
    caller = Echo(name="caller")
    try:
        await echo.join(team)
        await caller.join(team)
        ticket = await caller.ask("echo", "ping")
        print(ticket.state)
        if ticket.state == "completed":
            print(ticket.content)
    finally:
        await echo.leave()
        await caller.leave()
        await team.stop()

asyncio.run(main())
```

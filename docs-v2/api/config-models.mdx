Team file models for `[tool.agentconnect]` and `agentconnect.toml`.

Embedded `Team("name").start()` needs no file. This file describes a
Team the CLI can start with `agentconnect up`: store, embeddings,
hosted Agents, and extra MCP tools. Secrets stay in the environment.

```
from agentconnect.config import TeamConfig, load_team_config

config = load_team_config()
config.team
config.agents[0].class_path
```

The example file is generated from [`TeamConfig.example`](/api/config-models#agentconnect-config-models-teamconfig-example) so the
committed TOML cannot drift from these fields.

## `HostedAgentConfig`

One Agent this Team process constructs and joins.

`class` is `module:Name`. That name is a [`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent) subclass, or a
function `create(name) -> BaseAgent` that returns an unjoined Agent.
`name` is unique within the Team.

```toml
[[tool.agentconnect.agents]]
class = "agents.writer:Writer"
name = "writer"
```

<a id="agentconnect-config-models-hostedagentconfig-class-path"></a>

### `class_path`

```python
class_path: str
```

Import path module:Name of a BaseAgent subclass or a function create(name) that returns an unjoined BaseAgent.

Required.

* `alias`: `'class'`
* `min_length`: `1`

<a id="agentconnect-config-models-hostedagentconfig-name"></a>

### `name`

```python
name: str
```

Agent name, unique within the Team.

Required.

* `min_length`: `1`
* `max_length`: `63`

## `TeamConfig`

Contents of a Team file.

```toml
[tool.agentconnect]
team = "content-squad"
store = "memory"
embeddings = "auto"
host = "127.0.0.1"
port = 9000
require_join_auth = true

[[tool.agentconnect.agents]]
class = "agents.writer:Writer"
name = "writer"
```

<a id="agentconnect-config-models-teamconfig-team"></a>

### `team`

```python
team: str
```

Team name, a lowercase DNS label.

Required.

<a id="agentconnect-config-models-teamconfig-store"></a>

### `store`

```python
store: str = 'memory'
```

memory, or a Redis URL such as redis\://localhost:6379/0.

Default: `'memory'`.

<a id="agentconnect-config-models-teamconfig-embeddings"></a>

### `embeddings`

```python
embeddings: str = 'auto'
```

auto | none | hashed | fastembed | openai | litellm, with optional :model on the last three.

Default: `'auto'`.

<a id="agentconnect-config-models-teamconfig-host"></a>

### `host`

```python
host: str = '127.0.0.1'
```

Loopback address agentconnect up binds.

Default: `'127.0.0.1'`.

<a id="agentconnect-config-models-teamconfig-port"></a>

### `port`

```python
port: int = 9000
```

TCP port agentconnect up binds.

Default: `9000`.

* `ge`: `1`
* `le`: `65535`

<a id="agentconnect-config-models-teamconfig-require-join-auth"></a>

### `require_join_auth`

```python
require_join_auth: bool = True
```

When true, every join needs a join token and identity proof.

Default: `True`.

<a id="agentconnect-config-models-teamconfig-agents"></a>

### `agents`

```python
agents: List[HostedAgentConfig]
```

Agents this process constructs and joins. Each class is a BaseAgent subclass or a function create(name) -> BaseAgent. Independently deployed Agents join by URL and are not listed.

Default factory: `list`.

<a id="agentconnect-config-models-teamconfig-tools"></a>

### `tools`

```python
tools: List[str]
```

Extra MCP tools as module:function import paths.

Default factory: `list`.

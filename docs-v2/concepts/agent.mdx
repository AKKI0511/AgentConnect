An **Agent** is a member, not a chat session. The public client is `BaseAgent`. Give it a Profile, implement `handle`, and join a Team.

A Skill is a named capability on that Profile. The Directory indexes skills so other agents can search.

```python
from agentconnect import AgentProfile, BaseAgent, Skill

class Writer(BaseAgent):
    profile = AgentProfile(
        summary="Writes short drafts from notes.",
        skills=[Skill(name="drafting", description="Turn notes into a draft.")],
    )
```

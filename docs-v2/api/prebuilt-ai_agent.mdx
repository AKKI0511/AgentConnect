Model-backed Agent on a LiteLLM tool loop.

[`AIAgent`](/api/prebuilt-ai_agent#agentconnect-prebuilt-ai-agent-aiagent) is a convenience on :class:`~agentconnect.agent.base.BaseAgent`.
It is not the product. Subclass [`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent) when you already have a model
loop. Use this helper when you want a model string, Team tools, and optional
custom tools without wiring LiteLLM yourself.

Install the extra first::

```
pip install 'agentconnect[aiagent]'

from agentconnect.prebuilt import AIAgent
from agentconnect.core.profile import AgentProfile, Skill
from agentconnect.team import Team

class Writer(AIAgent):
    profile = AgentProfile(
        summary="Writes short drafts from notes.",
        skills=[
            Skill(
                name="drafting",
                description="Turn notes into a two-paragraph draft.",
            )
        ],
    )

    def __init__(self, name: str = "writer"):
        super().__init__(
            name=name,
            model="gpt-4o-mini",
            instructions="Write short, plain drafts.",
        )

team = await Team("content-squad").start()
await Writer().join(team)
```

Conversation state for Team work comes from `ctx.history`. Team tools
(`find`, `ask`, `tell`, `get_result`, `get_history`,
`get_profiles`) are attached from the Session. Extra tools are yours:
pass a plain annotated function or an explicit [`Tool`](/api/agent-tools#agentconnect-agent-tools-tool).

`model` is a LiteLLM model id, for example `gpt-4o-mini` or
`gemini/gemini-2.0-flash`. Provider keys stay in the environment.

## `AIAgent`

```python
AIAgent(name: str, *, model: str, profile: AgentProfile | Mapping[str, Any] | None = None, identity: Optional[AgentIdentity] = None, instructions: str = 'You are a helpful teammate. Use tools when they help you do the work.', tools: Optional[Sequence[ToolLike]] = None, max_tool_rounds: int = DEFAULT_MAX_ROUNDS, completion: Optional[CompletionOptions] = None, api_key: Optional[str] = None, complete: Optional[CompletionFn] = None, include_team_tools: bool = True, instance_id: Optional[str] = None, max_in_flight: int = 1, join_token: Optional[str] = None)
```

[`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent) that answers with a LiteLLM model and a short tool loop.

agent = AIAgent(name="assistant", model="gpt-4o-mini")
await agent.join(team)
reply = await agent.chat("What does this Team do?")

Create a model-backed Agent. It has not joined a Team yet.

**Parameters:**

* `name` (`str`): Agent name, unique within the Team.

* `model` (`str`): LiteLLM model id, for example `gpt-4o-mini`.

* `profile` (`AgentProfile | Mapping[str, Any] | None`): Discovery Profile mapping or [`AgentProfile`](/api/core-profile#agentconnect-core-profile-agentprofile). A class
  attribute named `profile` is used when this is omitted.

* `instructions` (`str`): System prompt for every model call.

* `tools` (`Optional[Sequence[ToolLike]]`): Extra tools besides the Session Team tools. Each item is a
  plain annotated function or an explicit [`Tool`](/api/agent-tools#agentconnect-agent-tools-tool).

* `max_tool_rounds` (`int`): Cap on model→tool→model cycles per turn.

* `completion` (`Optional[CompletionOptions]`): Extra LiteLLM kwargs such as `temperature`.

* `api_key` (`Optional[str]`): Optional key. LiteLLM also reads provider env vars.

* `complete` (`Optional[CompletionFn]`): Advanced. Replace LiteLLM with another async callable
  of the same shape. Tests use this for a recorded model.

* `include_team_tools` (`bool`): When True (default), Session Team tools are
  attached on Team turns. `chat()` never attaches them.

Inherits from [`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent).

<a id="agentconnect-prebuilt-ai-agent-aiagent-handle"></a>

`async`

### `handle`

```python
handle(message: MailboxMessage, ctx: Context) -> str
```

Answer one Delivery with the model loop.

Thread history comes from `ctx.history`. Team tools attach when a
Session exists and `include_team_tools` is True.
[`ToolLoopExhausted`](/api/prebuilt-loop#agentconnect-prebuilt-loop-toolloopexhausted) is not caught here.

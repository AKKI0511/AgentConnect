Local Team Directory: member Profiles, stored vectors, ranked `find`.

The Directory lists this Team's Memberships only. It does not search other
Teams and it does not use a vector database. Vectors sit in the Team Store
beside Memberships. One `find` ranks in one embedding space.

**Examples:**

For a joined Agent:

```python
found = await agent.find("someone who can review a contract")
found.matches[0].address
```

## `Directory`

```python
Directory(store: Store, embedder: Embedder)
```

Rank this Team's members for a natural-language query.

The Runtime owns one Directory per Team. Pass `embeddings=` to
[`Team`](/api/team-runtime#agentconnect-team-runtime-team) to choose a backend. Most callers only use [`BaseAgent.find`](/api/agent-base#agentconnect-agent-base-baseagent-find).

Bind this Directory to `store` and `embedder`.

Ordinary Agent code does not construct a Directory.

**Parameters:**

* `store` ([`Store`](/api/team-store-base#agentconnect-team-store-base-store)): Team Store that holds Memberships and vectors.

* `embedder` ([`Embedder`](/api/team-directory-embedder#agentconnect-team-directory-embedder-embedder)): Embedding backend resolved from `Team(embeddings=...)`.

### `search`

```python
search(query: str, members: Sequence[Mapping[str, Any]], *, exclude_address: str, limit: int | None) -> FindResult
```

Rank `members` for `query` and return light cards.

Excludes `exclude_address`. Omitting `limit` returns every
remaining member, at most [`MAX_FIND_LIMIT`](/api/team-directory-directory#agentconnect-team-directory-directory-max-find-limit). Every match in
the result is ranked in one embedding space.

**Parameters:**

* `query` (`str`): Natural-language need.

* `members` (`Sequence[Mapping[str, Any]]`): Membership records with `address` and `profile`.

* `exclude_address` (`str`): Qualified Address to omit, usually the caller.

* `limit` (`int | None`): Maximum matches. Omit for every remaining member, at
  most 100.

**Returns:**

* ([`FindResult`](/api/core-directory#agentconnect-core-directory-findresult)): A [`FindResult`](/api/core-directory#agentconnect-core-directory-findresult) with `matches` ordered best-first.

## `profile_windows`

```python
profile_windows(profile: Mapping[str, Any], limit: int | None) -> list[str]
```

Bounded Profile windows for one embedding space.

When `limit` is omitted, the whole Profile is one window and the
embedder owns token splitting. Otherwise later Skills keep their own
character windows.

**Parameters:**

* `profile` (`Mapping[str, Any]`): Discovery Profile mapping.

* `limit` (`int | None`): Maximum characters per window, or None when unbounded.

**Returns:**

* (`list[str]`): One or more text windows to embed.

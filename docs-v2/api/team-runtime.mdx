Runtime for one named Team.

[`Team`](/api/team-runtime#agentconnect-team-runtime-team) is a Runtime object in this process. This module never holds
Agent objects. Agents pull work through a Session and may share this
process (embedded join), be hosted by `agentconnect up`, or join a
served origin by URL.

Construct `Team("name")`, then `start`. Embedded joins omit credentials
unless `require_join_auth=True`. `serve` binds loopback HTTP and mounts
Team MCP at `{origin}/mcp`. For authenticated or non-loopback serving,
pass the started Team to [`agentconnect.team.http.create_runtime_app`](/api/team-http#agentconnect-team-http-create-runtime-app).

Token-taking methods (`send`, `lease`, `reply`, and the rest) are the
Session transport. HTTP, MCP, and the in-process Session call them by
name. Agent code uses [`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent).

`store="memory"` (default) is process-local. Pass a Redis URL when
memberships, mailboxes, open Tickets, and Thread history must survive a
Runtime restart. Shared Redis does not make extra Runtime replicas safe.

Constructor bounds (`wait_hold_seconds`, `work_lifetime_seconds`,
`max_held_waits`, and the others) are documented on [`Team`](/api/team-runtime#agentconnect-team-runtime-team).

**Examples:**

Start an embedded Team. This fragment runs inside an async function:

```python
team = await Team("demo").start()
print(team.name, team.persistence)
await team.stop()
```

```python
Team(name: str, *, store: Store | str | None = None, max_message_bytes: int = DEFAULT_MAX_MESSAGE_BYTES, max_mailbox_depth: int = DEFAULT_MAX_MAILBOX_DEPTH, delivery_history_limit: int = DEFAULT_DELIVERY_HISTORY_LIMIT, wait_hold_seconds: float = DEFAULT_WAIT_HOLD_SECONDS, max_held_waits: int = DEFAULT_MAX_HELD_WAITS, work_lifetime_seconds: float = DEFAULT_WORK_LIFETIME_SECONDS, max_deadline_seconds: float = DEFAULT_MAX_DEADLINE_SECONDS, max_open_tickets: int = DEFAULT_MAX_OPEN_TICKETS, replay_horizon_seconds: float = DEFAULT_REPLAY_HORIZON_SECONDS, max_retained_bytes: int = DEFAULT_MAX_RETAINED_BYTES, session_ttl_seconds: float = DEFAULT_SESSION_TTL_SECONDS, lease_ttl_seconds: float = DEFAULT_LEASE_TTL_SECONDS, thread_message_limit: int = DEFAULT_THREAD_MESSAGE_LIMIT, max_instances: int = DEFAULT_MAX_INSTANCES, max_join_challenges: int = DEFAULT_MAX_JOIN_CHALLENGES, sweep_interval_seconds: float = SWEEP_INTERVAL_SECONDS, require_join_auth: bool = False, join_challenge_ttl_seconds: float = DEFAULT_JOIN_CHALLENGE_TTL_SECONDS, join_token_ttl_seconds: float = DEFAULT_JOIN_TOKEN_TTL_SECONDS, embeddings: EmbeddingsArg = 'auto', tools: Sequence[Callable[..., Any]] | None = None)
```

Runtime serving one Team.

A Team is an object in this process. Agents may join it in-process
(`BaseAgent.join(team)`), be hosted by `agentconnect up`, or join a
URL after `serve`. This object never holds Agent instances.

Process API: `start`, `stop`, `serve`, `join`,
`issue_join_token`, `revoke_join_token`, `status`,
`get_trace`, `remove_membership`.

Operations that take a Session token are the Session transport. HTTP,
MCP, and the in-process Session call them by name.

The Team owns Memberships, Sessions, Mailboxes, Deliveries, Tickets,
Thread history, and the Directory. `find` ranks other members from a
natural-language query. `serve` also mounts the Team MCP server
at `{origin}/mcp`. `status` reports `online` from stored Sessions.

Create an unstarted Runtime for Team `name`.

**Parameters:**

* `name` (`str`): Team name, a lowercase DNS label.

* `store` (`Store | str | None`): `"memory"` (default), a Redis URL such as
  `redis://127.0.0.1:6379/0`, or a [`Store`](/api/team-store-base#agentconnect-team-store-base-store). Memory does
  not survive process exit.

* `max_message_bytes` (`int`): Cap on UTF-8 JSON bytes of one Message or
  reply body. Defaults to 1,048,576. HTTP JSON bodies use
  the same cap.

* `max_mailbox_depth` (`int`): How many unleased items one Mailbox may
  hold. Further sends fail with `busy`. Defaults to 1,000.

* `delivery_history_limit` (`int`): How many earlier Thread Messages a
  Delivery may carry when `delivery_history="bodies"`.
  Defaults to 50. Older turns are on `get_history`.

* `wait_hold_seconds` (`float`): How long `collect=wait` may keep `send`
  open. Defaults to 25. After this the current Ticket is
  returned even if it is still open; collect the rest with
  `get_result`. Ending the wait does not cancel work.

* `max_held_waits` (`int`): How many `collect=wait` sends one Membership
  may hold at once. Defaults to 16. Further waits fail
  with `wait_limit`.

* `work_lifetime_seconds` (`float`): Finite work cutoff in seconds stamped
  on a new request whose send omitted `deadline` and that
  has no request parent to inherit from. Defaults to 3,600.
  Must not exceed `max_deadline_seconds`. This is a cutoff,
  not a completion estimate.

* `max_deadline_seconds` (`float`): Farthest a new request deadline may be
  from acceptance, in seconds. Defaults to 86,400.

* `max_open_tickets` (`int`): Open Tickets one Membership may hold as
  requester. Defaults to 1,000.

* `replay_horizon_seconds` (`float`): How long an identical send, reply, or
  complete still returns the original result after the
  obligation ends. Defaults to 86,400.

* `max_retained_bytes` (`int`): Cap on UTF-8 JSON bytes of retained
  Message bodies. Defaults to 67,108,864.

* `session_ttl_seconds` (`float`): Idle Session lifetime in seconds.
  Defaults to 300. Heartbeat refreshes it.

* `lease_ttl_seconds` (`float`): How long a Delivery lease lasts without
  renew, in seconds. Defaults to 60.

* `thread_message_limit` (`int`): History is trimmed to this many
  Messages once no live Delivery or Ticket window still
  needs an older one. Defaults to 10,000.

* `max_instances` (`int`): Running copies one Membership may hold at
  once. Defaults to 100.

* `max_join_challenges` (`int`): How many unused join challenges may
  exist at once. Defaults to 128.

* `sweep_interval_seconds` (`float`): How often due Sessions, leases,
  Tickets, and join credentials are expired, in seconds.
  Defaults to 0.5.

* `require_join_auth` (`bool`): When True, every join needs a join token
  and an identity proof, including in-process joins.

* `join_challenge_ttl_seconds` (`float`): Lifetime of a join challenge, in
  seconds. Defaults to 60.

* `join_token_ttl_seconds` (`float`): Default lifetime of a newly issued
  join token, in seconds. Defaults to 3,600.

* `embeddings` ([`EmbeddingsArg`](/api/team-directory-embedder#agentconnect-team-directory-embedder-embeddingsarg)): How Profiles are turned into vectors for `find`.
  `"auto"` uses a local ONNX model when
  `agentconnect[embeddings]` is installed, and hashed
  n-grams otherwise. An API key in the environment does
  not select a hosted embedder. `"openai"` and
  `"litellm"` are explicit hosted backends and need their
  extras (tiktoken; LiteLLM only for OpenAI or Azure
  embedding models). `"none"` forces hashed n-grams. Pass
  a callable `(list[str]) -> list[list[float]]` to supply
  your own embeddings. A failed backend is not mixed with
  leftover vectors; `find` rebuilds one space.

* `tools` (`Sequence[Callable[..., Any]] | None`): Extra MCP tools this Team serves beside the reserved
  Team tools. Each item is a callable whose `__name__` is
  the tool name. Reserved and duplicate names are rejected.

**Raises:**

* (`ValueError`): `name` is not a valid Team name, store or
  embeddings cannot be resolved, or a numeric bound is
  invalid.

### `join`

```python
join(name: str | None = None, agent_did: str | None = None, profile: Mapping[str, Any] | None = None, *, spec_version: str = SPEC_VERSION, instance_id: str | None = None, max_in_flight: int = DEFAULT_MAX_IN_FLIGHT, join_token: str | None = None, identity_proof: str | None = None, delivery_history: DeliveryHistoryForm | None = None, request: Mapping[str, Any] | None = None) -> JoinResult
```

Create or reconnect a Membership and open a Session.

Everyday Agent code calls [`BaseAgent.join`](/api/agent-base#agentconnect-agent-base-baseagent-join) instead of this
method. Embedded Teams accept joins without credentials. Pass
`join_token` and `identity_proof` when the Team was started with
`require_join_auth=True`, or when joining over HTTP with a token
the operator issued.

`name` is canonicalized to lowercase. A name and DID that already
belong together reconnect to that live Membership. After removal,
the same spelling is a new Membership. Any other clash fails with
`name_conflict`. `delivery_history="ids"` puts earlier Message
ids on each Delivery instead of Message bodies.

**Parameters:**

* `name` (`str | None`): Agent name, unique within the Team.

* `agent_did` (`str | None`): `did:key` of this Agent.

* `profile` (`Mapping[str, Any] | None`): Discovery Profile mapping (`summary`, `skills`, …).

* `instance_id` (`str | None`): Stable id for this running copy.

* `max_in_flight` (`int`): How many Deliveries this Session handles at
  once, 1 to 100.

* `join_token` (`str | None`): Token from `issue_join_token`.

* `identity_proof` (`str | None`): EdDSA JWT over a join challenge.

* `delivery_history` (`DeliveryHistoryForm | None`): `"bodies"` or `"ids"`.

* `request` (`Mapping[str, Any] | None`): Wire [`JoinRequest`](/api/core-operations#agentconnect-core-operations-joinrequest) mapping. When set, the other
  arguments are taken from it.

**Returns:**

* ([`JoinResult`](/api/core-operations#agentconnect-core-operations-joinresult)): A [`JoinResult`](/api/core-operations#agentconnect-core-operations-joinresult) with `session_token` and `address`.

<a id="agentconnect-team-runtime-team-send"></a>

`async`

### `send`

```python
send(session_token: str, request: Mapping[str, Any]) -> SendResult
```

Accept one request or event for one recipient in this Team.

Session transport. HTTP, MCP, and the in-process Session call
this by name. Everyday Agent code uses [`BaseAgent.ask`](/api/agent-base#agentconnect-agent-base-baseagent-ask) (or
`tell` for an event), not this method.

The Message, Ticket, Thread append, and Mailbox enqueue commit
together. A recipient cannot lease the item until that commit
finishes. `collect="wait"` holds until the Ticket is terminal or
`wait_hold_seconds` elapses, then returns the current Ticket.
Ending the wait does not cancel work; collect the rest with
`get_result`.

**Parameters:**

* `session_token` (`str`): Live Session token from `join`.

* `request` (`Mapping[str, Any]`): Send body. Required keys are `id` (client-generated
  UUID, becomes the Message id), `recipient` (Agent name or
  Address), `kind` (`"request"` or `"event"`), and
  `content` (JSON). A request also needs `collect`
  (`"wait"` or `"ticket"`). `deadline` may be omitted; the
  Runtime stamps `work_lifetime_seconds` or inherits a
  request parent's cutoff. An event must omit `collect`
  and `deadline`.

**Returns:**

* ([`SendResult`](/api/core-operations#agentconnect-core-operations-sendresult)): A [`SendResult`](/api/core-operations#agentconnect-core-operations-sendresult) (`status="ticketed"` with the current Ticket for a request, or `status="accepted"` with no Ticket for an event)

**Raises:**

* ([`TeamError`](/api/team-errors#agentconnect-team-errors-teamerror)): The Session is missing (`unauthorized`), the body
  is invalid (`invalid_request`, `invalid_address`,
  `address_outside_team`, `payload_too_large`), the
  recipient or parent is missing (`not_found`), the
  Mailbox is full (`busy`), too many waits are held
  (`wait_limit`), or the Team has not been started
  (`unavailable`).

**Examples:**

Session transport for a request that returns immediately:

```python
result = await team.send(
    session_token,
    {
        "id": message_id,
        "recipient": "writer",
        "kind": "request",
        "content": {"task": "draft"},
        "collect": "ticket",
    },
)
ticket_id = result.ticket.id
```

<a id="agentconnect-team-runtime-team-lease"></a>

`async`

### `lease`

```python
lease(session_token: str, max_items: int = 1) -> LeaseResult
```

Pull available work from the calling Membership's Mailbox.

Session transport. [`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent) leases for the handler. Each
Delivery must be finished with `reply` or `complete` before the
lease expires, or `renew` it. Empty `deliveries` means there is
no ready work, not an error.

**Parameters:**

* `session_token` (`str`): Live Session token from `join`.

* `max_items` (`int`): How many Deliveries to take, 1 to 100. Defaults
  to 1. Capped by remaining `max_in_flight` room on this
  Session.

**Returns:**

* ([`LeaseResult`](/api/core-operations#agentconnect-core-operations-leaseresult)): A [`LeaseResult`](/api/core-operations#agentconnect-core-operations-leaseresult) with `deliveries` (each item has `lease_id`, `lease_expires_at`, `attempt`, and `message`)

**Raises:**

* ([`TeamError`](/api/team-errors#agentconnect-team-errors-teamerror)): The Session is missing (`unauthorized`),
  `max_items` is out of range (`invalid_request`), or the
  Team has not been started (`unavailable`).

### `reply`

```python
reply(session_token: str, request: Mapping[str, Any]) -> ReplyResult
```

Finish a reply-expected Delivery with content or an error.

Session transport. [`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent) maps a handler return onto this

**Parameters:**

* `session_token` (`str`): Live Session token from `join`.

* `request` (`Mapping[str, Any]`): Reply body. Required keys are `id` (client-generated
  UUID), `lease_id`, and `outcome` (`"completed"` or
  `"failed"`). Completed replies need `content`. Failed
  replies need `error` (`code` and `message`).

**Returns:**

* ([`ReplyResult`](/api/core-operations#agentconnect-core-operations-replyresult)): A [`ReplyResult`](/api/core-operations#agentconnect-core-operations-replyresult) with the terminal Ticket.

**Raises:**

* ([`TeamError`](/api/team-errors#agentconnect-team-errors-teamerror)): The Session is missing (`unauthorized`), the body
  is invalid (`invalid_request` or `payload_too_large`),
  the lease is missing (`not_found`), the lease is no
  longer active (`lease_expired`), or the Ticket is already
  terminal (`ticket_closed`).

**Examples:**

```python
result = await team.reply(
    session_token,
    {
        "id": reply_id,
        "lease_id": delivery["lease_id"],
        "outcome": "completed",
        "content": "Draft complete.",
    },
)
print(result["ticket"]["state"])
```

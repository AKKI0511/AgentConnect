## `ErrorObject`

Public failure data shared by Runtime errors and handler failures.

`code` is a well-known [`ErrorCode`](/api/core-primitives#agentconnect-core-primitives-errorcode). An Agent application failure
code belongs in `details` of a `handler_failed` error.

**Attributes:**

* `code` ([`ErrorCode`](/api/core-primitives#agentconnect-core-primitives-errorcode)): Closed public error code.

* `message` (`str`): Safe human-readable explanation.

* `details` (`Optional[JsonObject]`): Optional structured data safe to reveal to the requester.

* `retryable` (`Optional[bool]`): Whether repeating the failed action may succeed
  without changing input. Omit when unknown.

Inherits from [`SchemaModel`](/api/core-base#agentconnect-core-base-schemamodel).

## `DeadlineExceededError`

Error stored by an expired Ticket.

A Ticket is the requester's record for one request. When its
deadline passes before an accepted reply, the Ticket is `expired`
and carries this object. `code` is always `deadline_exceeded`.

Inherits from [`ErrorObject`](/api/core-error#agentconnect-core-error-errorobject).

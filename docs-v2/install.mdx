## Python

<CodeGroup>

```bash pip
pip install agentconnect
```

```bash uv
uv add agentconnect
```

</CodeGroup>

## Extras

| Extra | Use |
| --- | --- |
| `redis` | Redis-backed store |
| `embeddings` | Local FastEmbed and hosted OpenAI/Azure tokenizers |
| `prebuilt` | `AIAgent`, `HumanAgent`, `TelegramAIAgent`, LiteLLM hosted embeddings |

```bash
pip install 'agentconnect[redis,embeddings,prebuilt]'
```

Hosted embeddings still need an explicit Team selection. An API key in the environment is not permission to send Profile text.

## Check

```bash
python -c "import agentconnect; print(agentconnect.__version__)"
```

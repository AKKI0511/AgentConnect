Errors raised by the agent Session client.

Catch `SessionError` on join, send, Directory, and delivery-finish
calls. `code` is a public Runtime error code. Branch on `code`, not on
the exception message.

**Examples:**

After `join`, branch on `code` when a send fails:

```python
from agentconnect import SessionError

try:
    await agent.ask("writer", {"task": "draft this"})
except SessionError as exc:
    print(exc.code, exc.message)
```

## `SessionError`

```python
SessionError(
    code: str,
    message: str,
    *,
    details: Optional[JsonObject] = None,
    retryable: Optional[bool] = None,
)
```

A Session or handler-facing Runtime operation failed.

`code` is a public Runtime error code such as `unauthorized`,
`invalid_request`, or `not_found`. Branch on `code`, not on the
exception message.

Record the public error `code` and human-readable `message`.

**Parameters:**

* `code` ([`str`](https://docs.python.org/3/library/stdtypes.html#str)): Public Runtime error code.

* `message` ([`str`](https://docs.python.org/3/library/stdtypes.html#str)): Human-readable explanation.

* `details` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`JsonObject`](/api/core-base#agentconnect-core-base-jsonobject)]): Optional JSON object with more data.

* `retryable` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`bool`](https://docs.python.org/3/library/functions.html#bool)]): Whether the caller may retry the same operation.

### `from_transport` `classmethod`


Agent Session: join, pull work, map handler outcomes, reconnect.

A Session talks to a Runtime through a transport. Embedded Teams use
in-process calls. A URL uses HTTP POST plus an SSE work hint. Agent code
does not change between them. [`BaseAgent.join`](/api/agent-base#agentconnect-agent-base-baseagent-join) constructs and starts a
Session. Construct [`Session`](/api/agent-session#agentconnect-agent-session-session) yourself only when you need the transport
without [`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent).

`instance_id` identifies this running copy. Re-joining with that same id
replaces this copy's Session. Two copies must not share an `instance_id`.

## `Session`

```python
Session(agent: 'BaseAgent', target: Any, *, instance_id: str, agent_did: str, profile: Mapping[str, Any], max_in_flight: int, delivery_history: DeliveryHistoryForm = 'bodies')
```

One running copy of an Agent connected to a Team.

[`BaseAgent.join`](/api/agent-base#agentconnect-agent-base-baseagent-join) constructs and starts this object. Construct it
yourself only when you need to drive the transport without
[`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent). `target` is a started [`Team`](/api/team-runtime#agentconnect-team-runtime-team) (in-process) or a Runtime
origin URL (HTTP).

After `start`, the Session pulls Deliveries, runs `handle`, maps
outcomes onto `reply` / `complete`, heartbeats, and reconnects when
the Team comes back with the same `instance_id`. Call `close` (or
[`BaseAgent.leave`](/api/agent-base#agentconnect-agent-base-baseagent-leave)) to disconnect. Membership, Mailbox, and Tickets
remain on the Team.

**Attributes:**

* `instance_id`: Id of this running copy.

* `agent_did`: DID this copy joined with.

* `max_in_flight`: How many Deliveries this Session may hold at once,
  including deferred replies that still hold a lease.

* `delivery_history`: `"bodies"` or `"ids"` for earlier Thread turns
  on each Delivery.

* `address` (`Optional[str]`): Qualified Address after join, otherwise `None`.

* `team_name` (`Optional[str]`): Team this copy joined, otherwise `None`.

* `session_token` (`Optional[str]`): Live Session token, otherwise `None`.

* `limits` (`dict[str, int | float]`): Runtime limits reported at join.

* `persistence` (`Optional[str]`): `"volatile"` or `"durable"` after join.

* `session_expires_at` (`Optional[str]`): When the Session token expires, otherwise
  `None`.

Bind this copy to a Team object or a Runtime URL.

**Parameters:**

* `agent` (`'BaseAgent'`): The [`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent) whose `handle` this Session will run.

* `target` (`Any`): A started [`Team`](/api/team-runtime#agentconnect-team-runtime-team), or a Runtime origin such as
  `http://127.0.0.1:9000`.

* `instance_id` (`str`): Id of this running copy. Two copies must not
  share this value.

* `agent_did` (`str`): DID presented at join.

* `profile` (`Mapping[str, Any]`): Discovery Profile mapping sent at join.

* `max_in_flight` (`int`): How many Deliveries this Session may hold at
  once, including deferred replies.

* `delivery_history` ([`DeliveryHistoryForm`](/api/core-primitives#agentconnect-core-primitives-deliveryhistoryform)): `"bodies"` (default) puts earlier Messages
  on each Delivery. `"ids"` puts only their ids.

### `start`

```python
start() -> 'Session'
```

Join the Team and start pull, heartbeat, events, and lease renew.

Retries while the Team is not up yet. After a disconnect, the
Session reconnects on its own with the same `instance_id`.

**Returns:**

* (`'Session'`): This Session, connected.

**Raises:**

* ([`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror)): Join was rejected. Branch on `code`
  (`unauthorized`, `name_conflict`, and other public
  codes).

<a id="agentconnect-agent-session-session-close"></a>

`async`

### `close`

```python
close(*, disconnect: bool = True) -> None
```

Stop pull, heartbeat, and renew. Optionally disconnect the Session.

Membership, Mailbox, and Tickets remain on the Team. Open Tickets
stay collectable after a later `join` with the same Membership.
This does not remove the Agent from the Team.

**Parameters:**

* `disconnect` (`bool`): When True (default), send disconnect for the
  current Session token. When False, stop local tasks
  without that call.

<a id="agentconnect-agent-session-session-ask"></a>

`async`

### `ask`

```python
ask(recipient: str, content: Any, *, deadline_seconds: Optional[float] = None, collect: CollectMode = 'wait', thread_id: Optional[str] = None, parent_id: Optional[str] = None, metadata: Optional[Mapping[str, Any]] = None, message_id: Optional[str] = None, deadline: Optional[str] = None, handling: Optional[Delivery] = None) -> Ticket
```

Send a reply-expected request.

`collect="wait"` (default) holds until the Ticket is terminal or
the Runtime wait hold elapses, then returns the current Ticket.
That Ticket may still be `open`. Ending the wait does not cancel
accepted work. Read a completed reply as `ticket.response.content`
after checking `ticket.state`. Collect later with `get_result`.

`collect="ticket"` returns immediately with the current Ticket.

Called from a handler, this send sets `parent_id` to the current
Message when you omit it. An omitted deadline inherits that
request's stamped cutoff. An explicit `deadline_seconds` becomes
an absolute timestamp. The Runtime rejects a child that exceeds
the parent. Outside `handle`, omitting `thread_id` leaves the
request unthreaded. From a handler, omitting it continues the
current Thread when `recipient` is the other party, and otherwise
starts a new Thread.

**Parameters:**

* `recipient` (`str`): Local name or same-Team qualified Address, for
  example `writer` or `writer@content-squad`.

* `content` (`Any`): The work, as text or JSON.

* `deadline_seconds` (`Optional[float]`): Work cutoff in seconds. Omit to inherit a
  request parent or the Runtime work lifetime. This is not
  how long this call waits.

* `collect` ([`CollectMode`](/api/core-primitives#agentconnect-core-primitives-collectmode)): `"wait"` (default) holds this call. `"ticket"`
  returns immediately. Neither cancels work.

* `thread_id` (`Optional[str]`): Continue this conversation with the same
  recipient. Omit outside `handle` for an unthreaded
  request. From a handler, omit to inherit or start as
  described above.

* `parent_id` (`Optional[str]`): Message this send answers. From a handler, omit
  to use the current Message.

* `metadata` (`Optional[Mapping[str, Any]]`): Optional JSON object stored on the Message.

* `message_id` (`Optional[str]`): Client-proposed Message id. Generated when
  omitted. For a request this becomes `Ticket.id`.

* `deadline` (`Optional[str]`): Absolute RFC 3339 cutoff. When set, it is used
  instead of `deadline_seconds`.

* `handling` (`Optional[Delivery]`): Delivery to inherit parent, Thread, and deadline
  from. From a handler this is the current Delivery.

**Returns:**

* ([`Ticket`](/api/core-ticket#agentconnect-core-ticket-ticket)): The current Ticket. It may still be `open` when a wait ends.

**Raises:**

* ([`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror)): The Agent is not connected, `collect` is not
  `wait` or `ticket`, or the Runtime rejected the send.
  Branch on `code`.

**Examples:**

Wait, then read a completed reply:

```python
ticket = await session.ask("writer", {"task": "draft this"})
if ticket.state == "completed":
    print(ticket.response.content)
```

Continue one conversation:

```python
import uuid

thread_id = str(uuid.uuid4())
await session.ask("writer", "outline this", thread_id=thread_id)
await session.ask("writer", "expand section 2", thread_id=thread_id)
```

### `tell`

```python
tell(recipient: str, content: Any, *, thread_id: Optional[str] = None, parent_id: Optional[str] = None, metadata: Optional[Mapping[str, Any]] = None, message_id: Optional[str] = None, handling: Optional[Delivery] = None) -> AcceptedSendResult
```

Send an event. No Ticket is created.

Acceptance means the Runtime queued the event, not that the
recipient finished handling it. Called from a handler, this send
sets `parent_id` to the current Message when you omit it.

**Parameters:**

* `recipient` (`str`): Local name or same-Team qualified Address.

* `content` (`Any`): The notice, as text or JSON.

* `thread_id` (`Optional[str]`): Continue this conversation with a current
  participant. Omit for an unthreaded notice, or to inherit
  from the current Delivery.

* `parent_id` (`Optional[str]`): Message this send answers. From a handler, omit
  to use the current Message.

* `metadata` (`Optional[Mapping[str, Any]]`): Optional JSON object stored on the Message.

* `message_id` (`Optional[str]`): Client-proposed Message id. Generated when
  omitted.

* `handling` (`Optional[Delivery]`): Delivery to inherit parent and Thread from. From a
  handler this is the current Delivery.

**Returns:**

* ([`AcceptedSendResult`](/api/core-operations#agentconnect-core-operations-acceptedsendresult)): An acknowledgement that the event was accepted.

**Raises:**

* ([`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror)): The Agent is not connected, or the Runtime
  rejected the send.

**Examples:**

```python
await session.tell("writer", {"note": "source changed"})
```

<a id="agentconnect-agent-session-session-get-result"></a>

`async`

### `get_result`

```python
get_result(ticket_id: str) -> Ticket
```

Return the current Ticket this Membership opened.

Repeatable. Does not consume the result. If `state` is `open`,
call again with the same id. Do not send another `ask`. The
Ticket includes the request `trace_id`.

**Parameters:**

* `ticket_id` (`str`): `Ticket.id` from `ask`, equal to the request
  Message id.

**Returns:**

* ([`Ticket`](/api/core-ticket#agentconnect-core-ticket-ticket)): The current Ticket, which may still be `open`.

**Raises:**

* ([`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror)): The Agent is not connected, or this Membership
  did not open that Ticket.

**Examples:**

```python
pending = await session.ask("writer", "long job", collect="ticket")
ticket = await session.get_result(pending.id)
if ticket.state == "completed":
    ticket.response.content
```

<a id="agentconnect-agent-session-session-get-history"></a>

`async`

### `get_history`

```python
get_history(thread_id: str, *, before: Optional[str] = None, limit: int = 50) -> HistoryResult
```

Return one page of retained Thread history, ordered by `seq`.

The newest page is first; turns inside a page are oldest to
newest. Omit `before` for the newest page. A UUID that is not
in the transcript, including one retention has removed, returns
that newest page. Only a participant may read the Thread.

**Parameters:**

* `thread_id` (`str`): Conversation id from a Ticket or Message.

* `before` (`Optional[str]`): Return Messages older than this id. Prefer
  `next_before` from the previous page.

* `limit` (`int`): Page size from 1 to 200. Defaults to 50.

**Returns:**

* ([`HistoryResult`](/api/core-operations#agentconnect-core-operations-historyresult)): One page. When `has_more` is true, pass `next_before` as

* ([`HistoryResult`](/api/core-operations#agentconnect-core-operations-historyresult)): the next `before`.

**Raises:**

* ([`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror)): The Agent is not connected, or is not a
  participant.

**Examples:**

```python
page = await session.get_history(thread_id)
if page.has_more:
    older = await session.get_history(
        thread_id, before=page.next_before
    )
```

`async`

### `reply_delivery`

```python
reply_delivery(delivery: Delivery | Mapping[str, Any], *, outcome: str, content: Any = None, error: Optional[Mapping[str, Any]] = None) -> dict[str, Any]
```

Finish a leased reply-expected Delivery.

Prefer [`DeferredReply.reply`](/api/agent-context#agentconnect-agent-context-deferredreply-reply) or [`DeferredReply.fail`](/api/agent-context#agentconnect-agent-context-deferredreply-fail) from a
handler. `outcome="completed"` stores `content` as the reply.
Any other `outcome` stores a failure. `None` is valid content.

**Parameters:**

* `delivery` (`Delivery | Mapping[str, Any]`): The leased Delivery, or a mapping with `lease_id`.

* `outcome` (`str`): `"completed"` to reply, or another value to fail.

* `content` (`Any`): Reply body when `outcome` is `"completed"`.

* `error` (`Optional[Mapping[str, Any]]`): Failure object when `outcome` is not `"completed"`.
  When omitted, the stored error is `handler_failed` with
  message `failed`. Uncaught `handle` exceptions store
  `The handler failed.` instead.

**Returns:**

* (`dict[str, Any]`): The Runtime acknowledgement for this reply.

**Raises:**

* ([`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror)): The Session is not connected, the lease
  expired, or the Ticket is already closed.

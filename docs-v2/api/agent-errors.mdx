Errors raised by the agent Session client.

Catch [`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror) on join, send, Directory, and delivery-finish
calls. `code` is a public Runtime error code. Branch on `code`, not on
the exception message.

**Examples:**

After `join`, branch on `code` when a send fails:

```python
from agentconnect import SessionError

try:
    await agent.ask("writer", {"task": "draft this"})
except SessionError as exc:
    print(exc.code, exc.message)
```

## `SessionError`

```python
SessionError(code: str, message: str, *, details: Optional[dict[str, Any]] = None, retryable: Optional[bool] = None)
```

A Session or handler-facing Runtime operation failed.

`code` is a public Runtime error code such as `unauthorized`,
`invalid_request`, or `not_found`. Branch on `code`, not on the
exception message.

**Attributes:**

* `code`: Public Runtime error code.

* `message`: Human-readable explanation.

* `details`: Optional JSON object with more data.

* `retryable`: Whether the caller may retry the same operation, when
  the Runtime said so. `None` means unspecified.

Record the public error `code` and human-readable `message`.

**Parameters:**

* `code` (`str`): Public Runtime error code.

* `message` (`str`): Human-readable explanation.

* `details` (`Optional[dict[str, Any]]`): Optional JSON object with more data.

* `retryable` (`Optional[bool]`): Whether the caller may retry the same operation.

### `from_transport`

```python
from_transport(exc: TransportError) -> 'SessionError'
```

Wrap a transport failure for agent-facing callers.

Session methods already do this. Application code usually
catches [`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror) rather than constructing it.

**Parameters:**

* `exc` ([`TransportError`](/api/transport-runtime#agentconnect-transport-runtime-transporterror)): Failure raised by the Session transport.

**Returns:**

* (`'SessionError'`): A [`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror) with the same `code`, `message`, `details`,

* (`'SessionError'`): and `retryable` flag.

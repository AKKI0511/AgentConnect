Model-backed `BaseAgent` that calls LiteLLM for you.

Use `AIAgent` when you have a model id and want that model to answer
Team requests. Subclass `BaseAgent` when your harness already does.
`model` is a LiteLLM model id. Provider keys stay in the environment.
Pass your own functions as `tools`. Pass `complete` to replace LiteLLM.

**Examples:**

`team` is started and `researcher` has joined it. After
`pip install 'agentconnect[aiagent]'`:

```python
from agentconnect.prebuilt import AIAgent

writer = AIAgent(
    name="writer",
    model="gpt-4o-mini",
    instructions="Draft short release notes from the request.",
)
await writer.join(team)
ticket = await researcher.ask("writer", "Draft a release note: search is faster.")
if ticket.state == "completed":
    print(ticket.response.content)
```

## `AIAgent`

```python
AIAgent(
    name: str,
    *,
    model: str,
    profile: AgentProfile | Mapping[str, object] | None = None,
    identity: Optional[AgentIdentity] = None,
    instructions: str = 'You are a helpful teammate. Use tools when they help you do the work.',
    tools: Optional[Sequence[ToolLike]] = None,
    max_tool_rounds: int = 8,
    completion: Optional[CompletionOptions] = None,
    api_key: Optional[str] = None,
    complete: Optional[CompletionFn] = None,
    include_team_tools: bool = True,
    instance_id: Optional[str] = None,
    max_in_flight: int = 1,
    join_token: Optional[str] = None,
)
```

`BaseAgent` that answers with a LiteLLM model and a short tool loop.

`handle` reads `ctx.history` and can call Session tools. `chat` keeps
a local history and does not attach those tools. Pass `complete` to
replace LiteLLM with another callable of the same shape. `ToolLoopExhausted`
propagates from `handle`, `chat`, and `complete`.

Create a model-backed Agent. It has not joined a Team yet.

**Parameters:**

* `name` ([`str`](https://docs.python.org/3/library/stdtypes.html#str)): Agent name, unique within the Team.

* `model` ([`str`](https://docs.python.org/3/library/stdtypes.html#str)): LiteLLM model id, for example `gpt-4o-mini`.

* `profile` ([`AgentProfile`](/api/core-profile#agentconnect-core-profile-agentprofile) | [`Mapping`](https://docs.python.org/3/library/collections.abc.html#collections.abc.Mapping)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str), [`object`](https://docs.python.org/3/library/functions.html#object)] | None): Discovery Profile mapping or `AgentProfile`. A class
  attribute named `profile` is used when this is omitted.

* `identity` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`AgentIdentity`](/api/core-identity#agentconnect-core-identity-agentidentity)]): Optional Agent identity. Omit to create one.

* `instructions` ([`str`](https://docs.python.org/3/library/stdtypes.html#str)): System prompt for every model call.

* `tools` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`Sequence`](https://docs.python.org/3/library/collections.abc.html#collections.abc.Sequence)\[[`ToolLike`](/api/agent-tools#agentconnect-agent-tools-toollike)]]): Extra tools besides the Session Team tools. Each item is a
  plain annotated function or an explicit `Tool`.

* `max_tool_rounds` ([`int`](https://docs.python.org/3/library/stdtypes.html#int)): Cap on model-tool-model cycles per turn.

* `completion` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`CompletionOptions`](/api/prebuilt-ai_agent#agentconnect-prebuilt-ai-agent-completionoptions)]): Extra LiteLLM kwargs such as `temperature`.

* `api_key` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str)]): Optional key. LiteLLM also reads provider env vars.

* `complete` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`CompletionFn`](/api/prebuilt-loop#agentconnect-prebuilt-loop-completionfn)]): Replace LiteLLM with another async callable of the
  same shape.

* `include_team_tools` ([`bool`](https://docs.python.org/3/library/functions.html#bool)): When True (default), Session Team tools are
  attached on Team turns. `chat()` never attaches them.

* `instance_id` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str)]): Stable id for this running copy.

* `max_in_flight` ([`int`](https://docs.python.org/3/library/stdtypes.html#int)): How many Deliveries this Session handles at once.

* `join_token` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str)]): Token from `Team.issue_join_token`, when required.

**Raises:**

* [`ValueError`](https://docs.python.org/3/library/exceptions.html#ValueError): `model` is empty or `max_tool_rounds` is below 1.

Inherits from [`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent).

### `handle` `async`

```python
handle(message: MailboxMessage, ctx: Context) -> str
```

**Types:** [`MailboxMessage`](/api/core-message#agentconnect-core-message-mailboxmessage), [`Context`](/api/agent-context#agentconnect-agent-context-context).

### `complete` `async`

```python
complete(
    text: str,
    *,
    history: Optional[Sequence[Message | Mapping[str, object]]] = None,
    current: Message | Mapping[str, object] | str | None = None,
    include_team_tools: Optional[bool] = None,
    self_address: Optional[str] = None,
) -> str
```

Run one model turn. Used by `handle`, `chat`, and Telegram.

**Parameters:**

* `text` ([`str`](https://docs.python.org/3/library/stdtypes.html#str)): User turn when `current` is omitted.

* `history` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`Sequence`](https://docs.python.org/3/library/collections.abc.html#collections.abc.Sequence)\[[`Message`](/api/core-message#agentconnect-core-message-message) | [`Mapping`](https://docs.python.org/3/library/collections.abc.html#collections.abc.Mapping)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str), [`object`](https://docs.python.org/3/library/functions.html#object)]]]): Prior Messages or chat dicts. Defaults to empty.

* `current` ([`Message`](/api/core-message#agentconnect-core-message-message) | [`Mapping`](https://docs.python.org/3/library/collections.abc.html#collections.abc.Mapping)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str), [`object`](https://docs.python.org/3/library/functions.html#object)] | [`str`](https://docs.python.org/3/library/stdtypes.html#str) | None): This turn as a Message, chat dict, or string.

* `include_team_tools` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`bool`](https://docs.python.org/3/library/functions.html#bool)]): Override the constructor flag for this call.

* `self_address` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str)]): Address treated as this Agent in history.

**Returns:**

* ([`str`](https://docs.python.org/3/library/stdtypes.html#str)): Model text after the tool loop.

**Raises:**

* [`ToolLoopExhausted`](/api/prebuilt-loop#agentconnect-prebuilt-loop-toolloopexhausted): The model was still calling tools after
  `max_tool_rounds`.

**Examples:**

```python
reply = await agent.complete("Summarize the notes.")
```

<a id="agentconnect-prebuilt-ai-agent-aiagent-chat"></a>

### `chat` `async`

```python
chat(query: str, *, conversation_id: str = 'chat') -> str
```

Talk to this Agent without a Team.

History stays on this object, under `conversation_id`, and is
not a Team Thread. Session tools are not included.
`ToolLoopExhausted` reaches the caller.

**Examples:**

```python
reply = await agent.chat("What is a Ticket?")
follow = await agent.chat("Give an example.", conversation_id="chat")
```

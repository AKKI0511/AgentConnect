use the wire bodies for admission, delivery and collection. Model-facing
views keep the same outcomes with less data; use their own parsers.

## `JoinChallenge`

Short-lived challenge used to prove Agent DID control.

A DID is the Agent's `did:key` identity. The Client signs this
challenge with [`issue_identity_proof`](/api/core-identity#agentconnect-core-identity-issue-identity-proof) and sends the JWT as
`identity_proof` on join.

Inherits from [`SchemaModel`](/api/core-base#agentconnect-core-base-schemamodel).

<a id="agentconnect-core-operations-joinchallenge-nonce"></a>

### `nonce`

```python
nonce: str
```

At least 128 bits of random data in base64url form.

* `pattern`: `'^[A-Za-z0-9_-]{22,64}$'`

<a id="agentconnect-core-operations-joinchallenge-audience"></a>

### `audience`

```python
audience: str
```

Exact JWT audience required by the Runtime.

* `pattern`: `'^agentconnect:[a-z0-9](?:[a-z0-9-]{0,61}[a-z0-9])?$'`

<a id="agentconnect-core-operations-joinchallenge-expires-at"></a>

### `expires_at`

```python
expires_at: Timestamp
```

Time after which this challenge cannot authenticate a join.

Optional ready-made Agents on top of [`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent).

The product is [`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent) plus a Team. This package is convenience:
a LiteLLM loop, a stdin human, and a Telegram bot. None of these is
required to join a Team.

[`AIAgent`](/api/prebuilt-ai_agent#agentconnect-prebuilt-ai-agent-aiagent) needs `pip install 'agentconnect[aiagent]'`. [`HumanAgent`](/api/prebuilt-human_agent#agentconnect-prebuilt-human-agent-humanagent)
needs `pip install 'agentconnect[cli]'`. [`TelegramAIAgent`](/api/prebuilt-telegram-telegram_agent#agentconnect-prebuilt-telegram-telegram-agent-telegramaiagent) needs
`pip install 'agentconnect[telegram]'`. [`Tool`](/api/agent-tools#agentconnect-agent-tools-tool) is the same callable
wrapper as [`agentconnect.agent.tools.Tool`](/api/agent-tools#agentconnect-agent-tools-tool).

Pass extra tools as annotated functions or explicit [`Tool`](/api/agent-tools#agentconnect-agent-tools-tool) objects.
Team coordination tools (`find`, `ask`, `tell`, `get_result`,
`get_history`, `get_profiles`) attach from the Session. `model` is a
LiteLLM model id. Provider keys stay in the environment.

**Examples:**

For a started Team, after `pip install 'agentconnect[aiagent]'`.
Close the Session with `leave` when finished:

```python
from agentconnect.prebuilt import AIAgent

agent = AIAgent(name="assistant", model="gpt-4o-mini")
await agent.join(team)
await agent.leave()
```

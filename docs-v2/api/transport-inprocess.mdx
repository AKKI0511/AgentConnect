In-process Runtime transport.

Calls operations on a Team-like object by method name. This module does
not import [`agentconnect.team`](/api/team), so `agent/` can use it without crossing
the import boundary. Everyday Agent code uses [`BaseAgent.join`](/api/agent-base#agentconnect-agent-base-baseagent-join) with a
started Team rather than constructing this class.

* [`InProcessTransport`](/api/transport-inprocess#agentconnect-transport-inprocess-inprocesstransport)

## `InProcessTransport`

```python
InProcessTransport(runtime: Any)
```

Runtime operations as direct calls on an embedded Team.

Session transport. Token-taking methods match [`Team`](/api/team-runtime#agentconnect-team-runtime-team) by name.

Call operations on `runtime` by method name. Does not import team.

**Parameters:**

* `runtime` (`Any`): A started [`Team`](/api/team-runtime#agentconnect-team-runtime-team).

**Raises:**

* (`TypeError`): `runtime` is missing or is a string URL.

### `get_history`

```python
get_history(session_token: str, thread_id: str, *, before: str | None = None, limit: int = 50) -> dict[str, Any]
```

Return one page of retained Thread history.

**Parameters:**

* `session_token` (`str`): Live Session token from `join`.

* `thread_id` (`str`): Thread id from a Message or Ticket.

* `before` (`str | None`): Return Messages older than this id. Omit for the
  newest page.

* `limit` (`int`): Page size from 1 to 200. Defaults to 50.

**Raises:**

* ([`TransportError`](/api/transport-runtime#agentconnect-transport-runtime-transporterror)): The Thread is missing or this Membership is
  not a participant.

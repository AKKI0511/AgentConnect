## `IndexSettings`

Process settings from `AGENTCONNECT_INDEX_*`.

`python -m agentconnect.index.service` listens on loopback only.

<a id="agentconnect-index-models-indexsettings-host"></a>

### `host`

```python
host: str = '127.0.0.1'
```

Loopback address used by the built-in server.

<a id="agentconnect-index-models-indexsettings-port"></a>

### `port`

```python
port: int = 8000
```

* `ge`: `1`
* `le`: `65535`

<a id="agentconnect-index-models-indexsettings-log-level"></a>

### `log_level`

```python
log_level: str = 'INFO'
```

<a id="agentconnect-index-models-indexsettings-allowed-origins"></a>

### `allowed_origins`

```python
allowed_origins: list[str]
```

CORS origins the built-in server allows.

<a id="agentconnect-index-models-indexsettings-model-name"></a>

### `model_name`

```python
model_name: str = 'hashed'
```

hashed, or a fastembed model id. A failed load stops startup.

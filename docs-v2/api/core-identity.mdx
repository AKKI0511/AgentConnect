Agent-owned keys, join proofs and Team-signed membership statements.

Persist the Agent's key when you need to reconnect to its retained Membership.
A join proof shows key control for a fresh Runtime challenge. A membership
attestation is a separate statement signed by the Team; it does not grant
admission or Session authority. The Runtime does not accept inbound attestations.

## `issue_identity_proof`

```python
issue_identity_proof(
    identity: AgentIdentity,
    challenge: JoinChallenge,
    *,
    now: Optional[datetime] = None,
) -> str
```

Sign a fresh Runtime challenge to prove control of the Agent DID.

Send the JWT as `identity_proof` alongside the Team's join invitation. The
proof alone does not authorize admission.

**Parameters:**

* `identity` ([`AgentIdentity`](/api/core-identity#agentconnect-core-identity-agentidentity)): Must hold the Agent private key.

* `challenge` ([`JoinChallenge`](/api/core-operations#agentconnect-core-operations-joinchallenge)): Runtime JoinChallenge, including audience, nonce and expiry.

* `now` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`datetime`](https://docs.python.org/3/library/datetime.html#datetime.datetime)]): Override the current UTC clock used for issuance.

**Raises:**

* [`ValueError`](https://docs.python.org/3/library/exceptions.html#ValueError): The private key is absent or the challenge is invalid or expired.

<a id="agentconnect-core-identity-verify-identity-proof"></a>

## `verify_identity_proof`

```python
verify_identity_proof(
    token: str,
    *,
    agent_did: AgentDid,
    challenge: JoinChallenge,
    now: Optional[datetime] = None,
) -> JsonObject
```

**Types:** [`JoinChallenge`](/api/core-operations#agentconnect-core-operations-joinchallenge), [`JsonObject`](/api/core-base#agentconnect-core-base-jsonobject).

Verify key control and claims against the supplied join challenge.

The caller must ensure the challenge is issued, unused and consumed atomically
with admission. This cryptographic check does not consume it.

**Parameters:**

* `agent_did` ([`AgentDid`](/api/core-primitives#agentconnect-core-primitives-agentdid)): Expected proof issuer.

* `now` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`datetime`](https://docs.python.org/3/library/datetime.html#datetime.datetime)]): Override the current UTC clock for expiry and issuance skew.

**Raises:**

* [`ValueError`](https://docs.python.org/3/library/exceptions.html#ValueError): The token, signature, timing or challenge claims are invalid.
  Admission callers should expose a single `unauthorized` failure.

<a id="agentconnect-core-identity-issue-membership-attestation"></a>

## `issue_membership_attestation`

```python
issue_membership_attestation(
    team_identity: AgentIdentity,
    *,
    agent_did: AgentDid,
    name: str,
    address: str,
    team_name: str,
    now: Optional[datetime] = None,
    ttl_seconds: int = 365 * 24 * 60 * 60,
) -> str
```

**Types:** [`AgentDid`](/api/core-primitives#agentconnect-core-primitives-agentdid).

Sign a statement that this Team vouches for an Agent's membership.

The statement includes the Agent DID, Team, name, Address and lifetime.
It is separate from join invitations and Session credentials. The current
Runtime issues these statements but does not admit callers using them.

**Parameters:**

* `team_identity` ([`AgentIdentity`](/api/core-identity#agentconnect-core-identity-agentidentity)): Must hold the Team private key.

* `name` ([`str`](https://docs.python.org/3/library/stdtypes.html#str)): Membership name to record alongside its qualified Address.

* `now` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`datetime`](https://docs.python.org/3/library/datetime.html#datetime.datetime)]): Override the current UTC issuance clock.

* `ttl_seconds` ([`int`](https://docs.python.org/3/library/stdtypes.html#int)): Lifetime measured from issuance.

**Raises:**

* [`ValueError`](https://docs.python.org/3/library/exceptions.html#ValueError): The Team key is absent or the Agent DID is not Ed25519.

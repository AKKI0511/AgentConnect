A **Message** is the payload. A **Delivery** is that payload sitting in a mailbox with lease and routing state. Handlers see a mailbox message. They do not operate the Runtime's queue.

Kinds you will meet first:

- `request` expects a reply
- `event` does not

```python
async def handle(self, msg: MailboxMessage, ctx: Context) -> str | None:
    if msg.kind != "request":
        return None
    return {"ok": True}
```

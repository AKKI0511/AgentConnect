Model tool loop owned by AgentConnect.

LiteLLM normalizes provider APIs. It does not run tools. This loop does:
call the model, run any tool calls, append results, repeat until the model
stops calling tools or `max_rounds` is hit.

When the turn budget is exhausted while the model is still calling tools,
[`ToolLoopExhausted`](/api/prebuilt-loop#agentconnect-prebuilt-loop-toolloopexhausted) is raised. That is an unsuccessful outcome, not
a successful string reply.

**Examples:**

```python
from agentconnect.prebuilt.loop import run_tool_loop
from agentconnect.prebuilt.tools import Tool

reply = await run_tool_loop(
    complete=litellm.acompletion,
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "ping the tool"}],
    tools=[Tool.from_callable(ping)],
)
```

## `ToolLoopExhausted`

```python
ToolLoopExhausted(max_rounds: int)
```

The model was still calling tools when `max_rounds` was reached.

Raised by [`run_tool_loop`](/api/prebuilt-loop#agentconnect-prebuilt-loop-run-tool-loop). [`AIAgent.handle`](/api/prebuilt-ai_agent#agentconnect-prebuilt-ai-agent-aiagent-handle) does not catch it, so
an in-Team request fails through the handler-failure path. `chat` and
`complete` let the same exception reach the caller.

**Attributes:**

* `max_rounds`: Turn budget that was exhausted.

## `CompletionFn`

Async callable with the LiteLLM `acompletion` shape.

The loop passes `model`, `messages`, and when tools exist, `tools`.
Extra keyword arguments from the caller (`temperature`, `api_key`,
and others) are forwarded unchanged.

## `run_tool_loop`

```python
run_tool_loop(*, complete: CompletionFn, model: str, messages: Sequence[Mapping[str, object]], tools: Sequence[ToolLike] | None = None, max_rounds: int = DEFAULT_MAX_ROUNDS, **complete_kwargs: object) -> str
```

Call `complete` until the model returns text or raise on exhaustion.

`messages` is an OpenAI-style chat history. The loop mutates a local copy
only. Tool results stay in that copy; they are not written to a Thread.
A tool exception becomes one error JSON payload and the loop continues.
Hitting `max_rounds` while tool calls remain raises [`ToolLoopExhausted`](/api/prebuilt-loop#agentconnect-prebuilt-loop-toolloopexhausted).

**Parameters:**

* `complete` ([`CompletionFn`](/api/prebuilt-loop#agentconnect-prebuilt-loop-completionfn)): Async callable with the LiteLLM `acompletion` shape.

* `model` (`str`): LiteLLM model id.

* `messages` (`Sequence[Mapping[str, object]]`): Chat history. Copied; the original is not mutated.

* `tools` (`Sequence[ToolLike] | None`): Callables or [`Tool`](/api/agent-tools#agentconnect-agent-tools-tool) objects. Omit when the model has none.

* `max_rounds` (`int`): Cap on model-tool-model cycles. Defaults to 8.

* `**complete_kwargs` (`object`): Extra kwargs forwarded to `complete`.

**Returns:**

* (`str`): Model text when it stops calling tools.

**Raises:**

* (`ValueError`): `max_rounds` is below 1.

* ([`ToolLoopExhausted`](/api/prebuilt-loop#agentconnect-prebuilt-loop-toolloopexhausted)): The model was still calling tools after
  `max_rounds`.

**Examples:**

```python
reply = await run_tool_loop(
    complete=scripted_complete,
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "hello"}],
)
```

## `messages_from_thread`

```python
messages_from_thread(history: Sequence[Message | Mapping[str, object]], current: Message | Mapping[str, object] | str, *, self_address: Optional[str] = None, instructions: Optional[str] = None) -> list[dict[str, object]]
```

Build a chat history from Runtime Messages (`ctx.history` plus this turn).

**Parameters:**

* `history` (`Sequence[Message | Mapping[str, object]]`): Earlier Thread Messages or chat dicts.

* `current` (`Message | Mapping[str, object] | str`): This turn as a Message, chat dict, or string.

* `self_address` (`Optional[str]`): Address treated as this Agent (`assistant` role).

* `instructions` (`Optional[str]`): Optional system prompt prepended to the history.

**Returns:**

* (`list[dict[str, object]]`): OpenAI-style chat messages.

**Examples:**

```python
messages = messages_from_thread(
    ctx.history, msg, self_address=agent.address
)
```

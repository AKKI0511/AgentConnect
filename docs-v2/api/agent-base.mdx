BaseAgent: subclass, give a Profile, implement `handle`.

Join a running Team in-process or by URL. The Session pulls work, maps
handler outcomes onto Runtime `reply` / `complete`, and reconnects
when the Team comes back.

**Examples:**

Join a Team this process is serving. `url` is the origin from
`team.serve()`. `Echo` is the subclass in the [`agentconnect`](/api-reference) package
example. Construct the Agent before issuing the token so `agent_did`
matches, including when `identity_path` reuses a saved key. Close the
Session with `leave` when finished:

```python
agent = Echo(name="echo", identity_path="echo.json")
issued = await team.issue_join_token(
    name="echo", agent_did=agent.agent_did
)
await agent.join(url, join_token=issued.token)
```

Handler outcomes:

* return a JSON value to reply to a request
* return None to decline that request, or to finish an event
* raise to fail the request. The requester sees `handler_failed` with
  the generic text `The handler failed.` Diagnostics stay in this
  process log. Pass a specific message with `ctx.defer().fail(...)`.
* call `ctx.defer()` and answer later through the returned handle.
  The Session renews that Delivery lease until the reply, the request
  deadline, disconnect, or revocation. The slot still counts toward
  `max_in_flight`.

Several running copies of one Agent share one Mailbox. Conversation
state belongs to the Thread (`ctx.history`), not to this process.

## `BaseAgent`

```python
BaseAgent(name: str, *, profile: AgentProfile | Mapping[str, Any] | None = None, identity: Optional[AgentIdentity] = None, identity_path: Optional[str | Path] = None, instance_id: Optional[str] = None, max_in_flight: int = 1, delivery_history: DeliveryHistoryForm = 'bodies', join_token: Optional[str] = None)
```

Client that joins a Team, pulls Deliveries, and runs a handler.

`name` is unique within the Team. `instance_id` identifies this
running copy. The SDK generates one unless you pass a stable value;
two copies must not share an `instance_id`. Pass `identity_path`
to persist the Agent key across process restarts.

Create an Agent that has not yet joined a Team.

**Parameters:**

* `name` (`str`): Agent name, unique within the Team.

* `profile` (`AgentProfile | Mapping[str, Any] | None`): Discovery [`AgentProfile`](/api/core-profile#agentconnect-core-profile-agentprofile)
  or a mapping with the same fields. A class attribute named
  `profile` is used when this is omitted.

* `identity` (`Optional[AgentIdentity]`): Optional keypair. A valid `did:key` on it is reused;
  otherwise the SDK mints one for join. Do not pass this
  together with `identity_path`. Callers that persist the
  key themselves can load it with [`load_identity`](/api/agent-identity#agentconnect-agent-identity-load-identity) and pass
  the result here.

* `identity_path` (`Optional[str | Path]`): JSON file for the Agent key. Loaded when it
  exists, otherwise created. Restarting with the same path
  keeps the same DID.

* `instance_id` (`Optional[str]`): Stable id for this running copy. Generated by default.

* `max_in_flight` (`int`): How many Deliveries this Session handles at once,
  including deferred replies that still hold a lease.

* `delivery_history` ([`DeliveryHistoryForm`](/api/core-primitives#agentconnect-core-primitives-deliveryhistoryform)): `"bodies"` (default) puts earlier Messages on
  each Delivery. `"ids"` puts only their ids; page bodies
  with `get_history`.

* `join_token` (`Optional[str]`): Token issued by the Team. Required when joining a
  Team that has `require_join_auth=True`. Also read from
  `AGENTCONNECT_JOIN_TOKEN`.

**Raises:**

* (`ValueError`): `name` is invalid, both `identity` and
  `identity_path` were passed, `instance_id` is not a UUID,
  or `max_in_flight` / `delivery_history` is out of range.

**Examples:**

Persist the Agent key across restarts:

```python
agent = Writer(name="writer", identity_path="writer.json")
```

`async`

### `join`

```python
join(team_or_url: Any, *, join_token: Optional[str] = None) -> 'BaseAgent'
```

Join a Team. Pass a started Team, or a URL this Team is serving.

Retries while the Team is not up yet. After a disconnect, the
Session reconnects on its own with the same `instance_id`.
Two copies must not share an `instance_id`.

**Parameters:**

* `team_or_url` (`Any`): A started [`Team`](/api/team-runtime#agentconnect-team-runtime-team) (in-process), or a Runtime
  origin such as `http://127.0.0.1:9000` (HTTP).

* `join_token` (`Optional[str]`): Overrides the constructor / environment token
  for this join. Required when the Team has
  `require_join_auth=True`.

**Returns:**

* (`'BaseAgent'`): This Agent, connected.

**Raises:**

* ([`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror)): Join was rejected. Branch on `code`
  (`unauthorized`, `name_conflict`, …).

### `leave`

```python
leave() -> None
```

Disconnect this Session. Membership, Mailbox, and Tickets remain.

Open Tickets stay on the Team. Collect them after `join` with
the same Membership. This does not remove the Agent from the
Team; the operator uses [`Team.remove_membership`](/api/team-runtime#agentconnect-team-runtime-team-remove-membership) for that.

<a id="agentconnect-agent-base-baseagent-ask"></a>

`async`

### `ask`

```python
ask(recipient: str, content: Any, *, deadline_seconds: Optional[float] = None, collect: CollectMode = 'wait', thread_id: Optional[str] = None, parent_id: Optional[str] = None, metadata: Optional[Mapping[str, Any]] = None) -> Ticket
```

Send a reply-expected request through this Session.

`collect="wait"` (default) holds until the Ticket is terminal or
the Runtime wait hold elapses, then returns the current Ticket.
That Ticket may still be `open`. Ending the wait does not end
accepted work. Read a completed reply as `ticket.response.content`
after checking `ticket.state`. Collect later with `get_result`.
Omit `deadline_seconds` to inherit a request parent or use the
Runtime work lifetime.

**Parameters:**

* `recipient` (`str`): Local name or same-Team qualified Address, for
  example `writer` or `writer@content-squad`.

* `content` (`Any`): The work, as text or JSON.

* `deadline_seconds` (`Optional[float]`): Work cutoff in seconds. Omit to inherit a
  request parent or the Runtime work lifetime. This is not
  how long this call waits.

* `collect` ([`CollectMode`](/api/core-primitives#agentconnect-core-primitives-collectmode)): `"wait"` (default) holds this call; `"ticket"`
  returns immediately. Neither cancels work.

* `thread_id` (`Optional[str]`): Continue this conversation with the same
  recipient. Omit outside `handle` to leave the request
  unthreaded. From `handle`, [`Context.ask`](/api/agent-context#agentconnect-agent-context-context-ask) inherits the
  current Thread when `recipient` is the other party, and
  otherwise starts a new Thread.

* `parent_id` (`Optional[str]`): Message this send answers. From a handler,
  [`Context.ask`](/api/agent-context#agentconnect-agent-context-context-ask) sets this for you.

* `metadata` (`Optional[Mapping[str, Any]]`): Optional JSON object stored on the Message.

**Returns:**

* ([`Ticket`](/api/core-ticket#agentconnect-core-ticket-ticket)): The current Ticket. It may still be `open` when a wait ends.

**Raises:**

* ([`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror)): The Agent has not joined, or the Runtime
  rejected the send. Branch on `code`.

**Examples:**

Wait, then read a completed reply:

```python
ticket = await agent.ask("writer", {"task": "draft this"})
if ticket.state == "completed":
    print(ticket.response.content)
```

Return immediately and collect later. `get_result` can still
return `open`:

```python
pending = await agent.ask("writer", "long job", collect="ticket")
ticket = await agent.get_result(pending.id)
if ticket.state == "completed":
    ticket.response.content
```

### `tell`

```python
tell(recipient: str, content: Any, *, thread_id: Optional[str] = None, parent_id: Optional[str] = None, metadata: Optional[Mapping[str, Any]] = None) -> AcceptedSendResult
```

Send an event through this Session. No Ticket is created.

Acceptance means the Runtime queued the event, not that the
recipient finished handling it.

**Parameters:**

* `content` (`Any`): The notice, as text or JSON.

  participant. Omit for an unthreaded notice.

* `parent_id` (`Optional[str]`): Message this send answers. From a handler,
  [`Context.tell`](/api/agent-context#agentconnect-agent-context-context-tell) sets this for you.

* `metadata` (`Optional[Mapping[str, Any]]`): Optional JSON object stored on the Message.

**Returns:**

* ([`AcceptedSendResult`](/api/core-operations#agentconnect-core-operations-acceptedsendresult)): An acknowledgement that the event was accepted.

**Raises:**

* ([`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror)): The Agent has not joined, or the Runtime
  rejected the send.

**Examples:**


<a id="agentconnect-agent-base-baseagent-get-history"></a>

`async`

### `get_history`

```python
get_history(thread_id: str, *, before: Optional[str] = None, limit: int = 50) -> HistoryResult
```

Return one page of retained Thread history.

The newest page is first; turns inside a page are oldest to
newest. Omit `before` for the newest page. A UUID that is not
in the transcript, including one retention has removed, returns
that newest page. Only a participant may read the Thread.

**Parameters:**

* `thread_id` (`str`): Conversation id from a Ticket or Message.

* `before` (`Optional[str]`): Return Messages older than this id. Prefer
  `next_before` from the previous page.

* `limit` (`int`): Page size from 1 to 200. Defaults to 50.

**Returns:**

* ([`HistoryResult`](/api/core-operations#agentconnect-core-operations-historyresult)): One page. When `has_more` is true, pass `next_before` as

* ([`HistoryResult`](/api/core-operations#agentconnect-core-operations-historyresult)): the next `before`.

**Raises:**

* ([`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror)): The Agent has not joined, or is not a
  participant.

**Examples:**

```python
page = await agent.get_history(thread_id)
if page.has_more:
    older = await agent.get_history(
        thread_id, before=page.next_before
    )
```

<a id="agentconnect-agent-base-baseagent-team-tools"></a>

### `team_tools`

```python
team_tools() -> TeamTools
```

Return Session-bound tools for this Agent.

Tools are `find`, `ask`, `tell`, `get_result`, `get_history`, and
`get_profiles`. Safe to call before `join`. The callables fail
until a Session exists. Use these when the host does not speak
MCP. Results are JSON. `ask` and `get_result` return a Ticket
view: branch on `state`, then read `content` when completed.

**Returns:**

* ([`TeamTools`](/api/agent-tools#agentconnect-agent-tools-teamtools)): Session-bound callables. Connecting a harness is adding the

* ([`TeamTools`](/api/agent-tools#agentconnect-agent-tools-teamtools)): Team MCP URL there instead.

**Examples:**

```python
tools = self.team_tools()
found = await tools.find(query="someone who can draft a summary")
ticket = await tools.ask(
    recipient=found["matches"][0]["address"],
    content=msg.content,
)
if ticket["state"] == "completed":
    return ticket["content"]
```

### `handle`

```python
handle(message: MailboxMessage, ctx: Context) -> JsonValue | None
```

Handle one Delivery.

Override this. `message` is the delivered request or event.
`ctx` is always a [`Context`](/api/agent-context#agentconnect-agent-context-context).

Return a JSON value to reply to a request. Return `None` to
decline that request, or to finish an event. Raise to fail the
request; the requester sees `handler_failed` with the generic
text `The handler failed.` Call `ctx.defer()` and answer later
through the returned handle.

**Parameters:**

* `message` ([`MailboxMessage`](/api/core-message#agentconnect-core-message-mailboxmessage)): The delivered request or event.

* `ctx` ([`Context`](/api/agent-context#agentconnect-agent-context-context)): Verified facts about this Delivery, plus `ask`, `tell`,
  `find`, and `defer`.

**Returns:**

* (`JsonValue | None`): Reply body, or `None` to decline or finish.

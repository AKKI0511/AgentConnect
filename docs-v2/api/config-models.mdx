## `HostedAgentConfig`

One Agent this Team process constructs and joins.

`entrypoint` is `module:Name`: a [`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent)
subclass or a synchronous factory. Both receive `name=<mapping key>` plus
optional `kwargs`. `kwargs` is owned by that class or factory; do not put
`name` there.

```toml
[agents.writer]
entrypoint = "agents.writer:Writer"
kwargs.model = "provider/model"
```

<a id="agentconnect-config-models-hostedagentconfig-entrypoint"></a>

### `entrypoint`

```python
entrypoint: str
```

Import path `module:Name` of a BaseAgent subclass or a synchronous factory create(name, \*\*kwargs) that returns an unjoined BaseAgent.

* `min_length`: `1`

## `TeamConfig`

Contents of a Team file.

A standalone `agentconnect.toml` uses this tree. `pyproject.toml` prefixes
the same tree with `[tool.agentconnect]`.

```toml
team = "content-squad"

[agents.researcher]
entrypoint = "agents.researcher:Researcher"

[agents.writer]
entrypoint = "agents.writer:Writer"
kwargs.model = "provider/model"
```

<a id="agentconnect-config-models-teamconfig-team"></a>

### `team`

```python
team: str
```

Team name, a lowercase DNS label.

<a id="agentconnect-config-models-teamconfig-store"></a>

### `store`

```python
store: str = 'memory'
```

memory, or a Redis URL such as `redis://localhost:6379/0`.

<a id="agentconnect-config-models-teamconfig-embeddings"></a>

### `embeddings`

```python
embeddings: str = 'auto'
```

auto, none, hashed, fastembed, openai, or litellm. The last three accept an optional :model suffix. auto uses a local ONNX model when the embeddings extra is installed, otherwise hashed n-grams, and does not send Profiles or queries to a hosted embedder.

<a id="agentconnect-config-models-teamconfig-host"></a>

### `host`

```python
host: str = '127.0.0.1'
```

Loopback address `agentconnect up` binds.

<a id="agentconnect-config-models-teamconfig-port"></a>

### `port`

```python
port: int = 9000
```

TCP port `agentconnect up` binds.

* `ge`: `1`
* `le`: `65535`

<a id="agentconnect-config-models-teamconfig-require-join-auth"></a>

### `require_join_auth`

```python
require_join_auth: bool = True
```

When true, every join needs a join token and identity proof.

<a id="agentconnect-config-models-teamconfig-agents"></a>

### `agents`

**Types:** [`HostedAgentConfig`](/api/config-models#agentconnect-config-models-hostedagentconfig).

Agents this process constructs and joins, keyed by canonical Agent name. Independently deployed Agents join by URL and are not listed.

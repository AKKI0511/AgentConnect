This Team's member Directory and Profile embedders.

`find` ranks every other Membership from a natural-language query.
Vectors live in the Team Store. There is no vector database and no
setting to turn search off. Ranking is not routing: `find` returns an
ordered list; `send` / `ask` use the Address you name.

Pass `embeddings=` to [`Team`](/api/team-runtime#agentconnect-team-runtime-team) only when you want a specific backend.
`"auto"` (default) uses a local ONNX model when `agentconnect[embeddings]`
is installed, otherwise hashed n-grams. An API key in the environment
does not select a hosted embedder. `"openai"` and `"litellm"` are
explicit hosted backends and send Profile text. `"none"` forces hashed
n-grams. Pass a callable `(list[str]) -> list[list[float]]` to supply
your own embeddings.

[`Directory`](/api/team-directory-directory#agentconnect-team-directory-directory-directory), [`Embedder`](/api/team-directory-embedder#agentconnect-team-directory-embedder-embedder), and [`HashedEmbedder`](/api/team-directory-embedder#agentconnect-team-directory-embedder-hashedembedder) are hosting extension
points. Ordinary Agent code calls [`BaseAgent.find`](/api/agent-base#agentconnect-agent-base-baseagent-find) / `get_entry`.

**Examples:**

Search from a joined Agent:

```python
found = await agent.find("someone who can review a contract")
address = found.matches[0].address
entry = await agent.get_entry(address)
print(entry.profile.summary)
```

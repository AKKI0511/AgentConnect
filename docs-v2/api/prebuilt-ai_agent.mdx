Model-backed Agent on a LiteLLM tool loop.

[`AIAgent`](/api/prebuilt-ai_agent#agentconnect-prebuilt-ai-agent-aiagent) is a convenience on [`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent). It is not the product.
Subclass [`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent) when you already have a model loop. Use this helper
when you want a model string, Team tools, and optional custom tools
without wiring LiteLLM yourself.

Conversation state for Team work comes from `ctx.history`. Team tools
(`find`, `ask`, `tell`, `get_result`, `get_history`, `get_profiles`)
are attached from the Session. Extra tools are yours: pass a plain
annotated function or an explicit [`Tool`](/api/agent-tools#agentconnect-agent-tools-tool).

`model` is a LiteLLM model id, for example `gpt-4o-mini` or
`gemini/gemini-2.0-flash`. Provider keys stay in the environment.

**Examples:**

For a started Team, after `pip install 'agentconnect[aiagent]'`.
Close the Session with `leave` when finished:

```python
from agentconnect.prebuilt import AIAgent

agent = AIAgent(name="writer", model="gpt-4o-mini")
await agent.join(team)
await agent.leave()
```

## `AIAgent`

```python
AIAgent(name: str, *, model: str, profile: AgentProfile | Mapping[str, object] | None = None, identity: Optional[AgentIdentity] = None, instructions: str = 'You are a helpful teammate. Use tools when they help you do the work.', tools: Optional[Sequence[ToolLike]] = None, max_tool_rounds: int = DEFAULT_MAX_ROUNDS, completion: Optional[CompletionOptions] = None, api_key: Optional[str] = None, complete: Optional[CompletionFn] = None, include_team_tools: bool = True, instance_id: Optional[str] = None, max_in_flight: int = 1, join_token: Optional[str] = None)
```

[`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent) that answers with a LiteLLM model and a short tool loop.

**Examples:**

```python
agent = AIAgent(name="assistant", model="gpt-4o-mini")
await agent.join(team)
reply = await agent.chat("What does this Team do?")
```

Create a model-backed Agent. It has not joined a Team yet.

**Parameters:**

* `name` (`str`): Agent name, unique within the Team.

* `model` (`str`): LiteLLM model id, for example `gpt-4o-mini`.

* `profile` (`AgentProfile | Mapping[str, object] | None`): Discovery Profile mapping or [`AgentProfile`](/api/core-profile#agentconnect-core-profile-agentprofile). A class
  attribute named `profile` is used when this is omitted.

* `identity` (`Optional[AgentIdentity]`): Optional Agent identity. Omit to create one.

* `instructions` (`str`): System prompt for every model call.

* `tools` (`Optional[Sequence[ToolLike]]`): Extra tools besides the Session Team tools. Each item is a
  plain annotated function or an explicit [`Tool`](/api/agent-tools#agentconnect-agent-tools-tool).

* `max_tool_rounds` (`int`): Cap on model-tool-model cycles per turn.

* `completion` (`Optional[CompletionOptions]`): Extra LiteLLM kwargs such as `temperature`.

* `api_key` (`Optional[str]`): Optional key. LiteLLM also reads provider env vars.

* `complete` (`Optional[CompletionFn]`): Replace LiteLLM with another async callable of the
  same shape.

* `include_team_tools` (`bool`): When True (default), Session Team tools are
  attached on Team turns. `chat()` never attaches them.

* `instance_id` (`Optional[str]`): Stable id for this running copy.

* `max_in_flight` (`int`): How many Deliveries this Session handles at once.

* `join_token` (`Optional[str]`): Token from [`Team.issue_join_token`](/api/team-runtime#agentconnect-team-runtime-team-issue-join-token), when required.

**Raises:**

* (`ValueError`): `model` is empty or `max_tool_rounds` is below 1.

Inherits from [`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent).

`async`

### `handle`

```python
handle(message: MailboxMessage, ctx: Context) -> str
```

Answer one Delivery with the model loop.

Thread history comes from `ctx.history`. Team tools attach when a
Session exists and `include_team_tools` is True.
[`ToolLoopExhausted`](/api/prebuilt-loop#agentconnect-prebuilt-loop-toolloopexhausted) is not caught here.

**Parameters:**

* `message` ([`MailboxMessage`](/api/core-message#agentconnect-core-message-mailboxmessage)): Incoming Delivery Message.

* `ctx` ([`Context`](/api/agent-context#agentconnect-agent-context-context)): Handler context for this Delivery.

<a id="agentconnect-prebuilt-ai-agent-aiagent-complete"></a>

`async`

### `complete`

```python
complete(text: str, *, history: Optional[Sequence[Message | Mapping[str, object]]] = None, current: Message | Mapping[str, object] | str | None = None, include_team_tools: Optional[bool] = None, self_address: Optional[str] = None) -> str
```

Run one model turn. Used by `handle`, `chat`, and Telegram.

**Parameters:**

* `text` (`str`): User turn when `current` is omitted.

* `history` (`Optional[Sequence[Message | Mapping[str, object]]]`): Prior Messages or chat dicts. Defaults to empty.

* `current` (`Message | Mapping[str, object] | str | None`): This turn as a Message, chat dict, or string.

* `include_team_tools` (`Optional[bool]`): Override the constructor flag for this call.

* `self_address` (`Optional[str]`): Address treated as this Agent in history.

**Returns:**

* (`str`): Model text after the tool loop.

**Raises:**

* ([`ToolLoopExhausted`](/api/prebuilt-loop#agentconnect-prebuilt-loop-toolloopexhausted)): The model was still calling tools after
  `max_tool_rounds`.

**Examples:**

```python
reply = await agent.complete("Summarize the notes.")
```

<a id="agentconnect-prebuilt-ai-agent-aiagent-chat"></a>

`async`

### `chat`

```python
chat(query: str, *, conversation_id: str = 'chat') -> str
```

Talk to this Agent without a Team. History is local to `conversation_id`.

Team tools are never attached. Join a Team and handle Deliveries
for teammate work.

**Parameters:**

* `query` (`str`): User text.

* `conversation_id` (`str`): Local history bucket. Defaults to `"chat"`.

**Returns:**

* (`str`): Model text.

**Raises:**

* ([`ToolLoopExhausted`](/api/prebuilt-loop#agentconnect-prebuilt-loop-toolloopexhausted)): The model was still calling tools after
  `max_tool_rounds`.

**Examples:**

```python
reply = await agent.chat("What is a Ticket?")
follow = await agent.chat("Give an example.", conversation_id="chat")
```

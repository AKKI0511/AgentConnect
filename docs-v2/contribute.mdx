Handwritten pages live next to `docs.json`. API pages under `api/` and `api-reference.mdx` are generated. Edit source, not generated MDX.

## Handwritten pages

1. Copy a template from [Page templates](/templates/overview).
2. Write the page under `docs-v2/`.
3. Add it to `docs.json` navigation or it will not appear.
4. Preview with `make docs-v2` and check with `make docs-v2-check`.

## API pages

1. Write **Google-style** docstrings. See [Docstrings](/guides/docstrings).
2. Run `make docs-v2-api`.
3. Commit the regenerated `docs-v2/api/**` and `api-reference.mdx`.

<Info>
  Package `__init__.py` content becomes the group landing page. The root package docstring is the API reference home.
</Info>

## Pull requests

Open PRs against the current docs branch while this tree lives in `docs-v2/`. Keep Sphinx `docs/` untouched until cutover.

This group is a layout dummy. It is not product documentation. Use it to check nested sidebar rows, cards, and framed images against the rest of the shell.

Open **Cards** and **Media** in the sidebar. Selecting a page in one group should leave the other group as you left it.

## Nested pages

- [Cards](/surfaces/cards)
- [Media](/surfaces/media)

## Layout checks

Use this section and its children to judge the On this page list. The parent heading should read brighter than the child when both are in view.

### Cards and media

Cards stay flat. Media uses a framed SVG. Neither is product documentation.

### Sidebar groups

Cards and Media start closed. Opening one should not restyle the row as a heading.

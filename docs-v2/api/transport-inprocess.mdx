## `InProcessTransport`

```python
InProcessTransport(runtime: RuntimeOperations)
```

Use the RuntimeTransport operations against a started Team in this process.

The caller owns the Team. Runtime failures become [`TransportError`](/api/transport-runtime#agentconnect-transport-runtime-transporterror);
async cancellation propagates. The shared operation contracts are described
on [`RuntimeTransport`](/api/transport-runtime#agentconnect-transport-runtime-runtimetransport). Ordinary agents select this transport with [`BaseAgent.join`](/api/agent-base#agentconnect-agent-base-baseagent-join).

Use an existing started Team; construction does not start it.

**Raises:**

* (`TypeError`): The supplied Runtime is absent or a URL.

Telegram Agent for AgentConnect.

[`TelegramAIAgent`](/api/prebuilt-telegram-telegram_agent#agentconnect-prebuilt-telegram-telegram-agent-telegramaiagent) extends [`AIAgent`](/api/prebuilt-ai_agent#agentconnect-prebuilt-ai-agent-aiagent) with a Telegram bot. Join a Team,
then `run()` to poll.

**Examples:**

For a started Team. Close the Session with `leave` when finished:

```python
from agentconnect.prebuilt import TelegramAIAgent

agent = TelegramAIAgent(
    name="telegram-bot",
    model="gpt-4o-mini",
    telegram_token="your_telegram_token",
)
await agent.join(team)
```

Immutable Message kinds and Delivery.

A handler receives a MailboxMessage (request or event) with attribute
access. A request always expects a reply. Fire-and-forget work is an
event. Response and error Messages are created by the Runtime on reply.

```
msg.kind
msg.content
msg.sender_did
msg.deadline   # requests only
msg.seq        # present when the Message belongs to a Thread
```

## `MessageBase`

Fields shared by every accepted Message.

`id` is Client-proposed on `send` and `reply` and stored
unchanged at acceptance. The Runtime sets canonical Addresses,
`sender_did`, `created_at`, `trace_id`, and `seq` when
`thread_id` is present. `seq` is present exactly when
`thread_id` is present. History and `before` cursors order by
`seq`, not by `created_at`.

Inherits from [`SchemaModel`](/api/core-base#agentconnect-core-base-schemamodel).

## `Delivery`

One exclusive attempt to handle a Message.

`history` is the bounded recent Thread window, ordered by `seq`
and excluding `message`. After `join(..., delivery_history="ids")`
`history` is empty and `history_ids` lists those earlier ids.

```
delivery.history
delivery.history_ids   # present only for ids mode
delivery.history_complete
```

Inherits from [`SchemaModel`](/api/core-base#agentconnect-core-base-schemamodel).

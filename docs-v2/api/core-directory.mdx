# `core.directory`
Directory entry, ranked match, and find result types.

## Classes

### `DirectoryEntry` <sup><a href="https://github.com/AKKI0511/AgentConnect/blob/team-restructure/agentconnect/core/directory.py#L28" target="_blank"><Icon icon="github" style="width: 14px; height: 14px;" /></a></sup>


Full Directory record for one Membership.

Runtime `get_profile` returns Address, DID, and Profile together.
The Client method is `get_entry`.

.. code-block:: python

```python
entry = await agent.get_entry("writer")
entry.profile.summary
entry.profile.description
```

### `DirectoryMatch` <sup><a href="https://github.com/AKKI0511/AgentConnect/blob/team-restructure/agentconnect/core/directory.py#L46" target="_blank"><Icon icon="github" style="width: 14px; height: 14px;" /></a></sup>


One ranked discovery result.

Light by default: Address, `summary`, Skill names, and Profile tags.
`detail='full'` adds `agent_did` and the complete Profile.


### `FindRequest` <sup><a href="https://github.com/AKKI0511/AgentConnect/blob/team-restructure/agentconnect/core/directory.py#L61" target="_blank"><Icon icon="github" style="width: 14px; height: 14px;" /></a></sup>

### `FindResult` <sup><a href="https://github.com/AKKI0511/AgentConnect/blob/team-restructure/agentconnect/core/directory.py#L69" target="_blank"><Icon icon="github" style="width: 14px; height: 14px;" /></a></sup>


Ordered local Directory search result.

Matches are best-first. The result does not name the embedding
backend or a fallback.

.. code-block:: python

```python
found = await agent.find("someone who can draft a summary")
found.matches[0].address
found.matches[0].summary
```

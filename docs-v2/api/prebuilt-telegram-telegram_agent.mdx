Telegram bot that is also an `AIAgent`.

Join a Team when teammates should reach this Agent, then `run` to poll.
Telegram chats keep their own history, separate from `ctx.history`, and
that history stops at 40 messages. `run` stops polling when cancelled
and does not call `leave`.

## `TelegramAIAgent`

```python
TelegramAIAgent(
    name: str,
    *,
    model: str,
    telegram_token: Optional[str] = None,
    instructions: str = 'You are a helpful Telegram assistant.',
    tools: Optional[Sequence[ToolLike]] = None,

    profile: AgentProfile | Mapping[str, object] | None = None,

    complete: Optional[CompletionFn] = None,

    include_team_tools: bool = True,
    groups_file: str = 'groups.txt',
    join_token: Optional[str] = None,

```

`AIAgent` that also polls Telegram.

Team deliveries use `handle`. Telegram chats keep their own history.

Create a Telegram-backed Agent. It has not joined a Team or started polling.

**Parameters:**

* `name` ([`str`](https://docs.python.org/3/library/stdtypes.html#str)): Agent name, unique within the Team.

* `model` ([`str`](https://docs.python.org/3/library/stdtypes.html#str)): LiteLLM model id.

* `telegram_token` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str)]): BotFather token. `TELEGRAM_BOT_TOKEN` is used
  when this is omitted.

* `instructions` ([`str`](https://docs.python.org/3/library/stdtypes.html#str)): System prompt for every model call.

* `tools` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`Sequence`](https://docs.python.org/3/library/collections.abc.html#collections.abc.Sequence)\[[`ToolLike`](/api/agent-tools#agentconnect-agent-tools-toollike)]]): Extra tools besides Telegram tools and Session Team tools.

* `identity` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`AgentIdentity`](/api/core-identity#agentconnect-core-identity-agentidentity)]): Optional Agent identity. Omit to create one.

* `profile` ([`AgentProfile`](/api/core-profile#agentconnect-core-profile-agentprofile) | [`Mapping`](https://docs.python.org/3/library/collections.abc.html#collections.abc.Mapping)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str), [`object`](https://docs.python.org/3/library/functions.html#object)] | None): Discovery Profile mapping or `AgentProfile`.

* `completion` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`CompletionOptions`](/api/prebuilt-ai_agent#agentconnect-prebuilt-ai-agent-completionoptions)]): Extra LiteLLM kwargs such as `temperature`.

* `api_key` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str)]): Optional key. LiteLLM also reads provider env vars.

* `complete` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`CompletionFn`](/api/prebuilt-loop#agentconnect-prebuilt-loop-completionfn)]): Replace LiteLLM with another async callable of the
  same shape.

* `max_tool_rounds` ([`int`](https://docs.python.org/3/library/stdtypes.html#int)): Cap on model-tool-model cycles per turn.

* `include_team_tools` ([`bool`](https://docs.python.org/3/library/functions.html#bool)): When True (default), Session Team tools are
  attached on Team turns and Telegram replies.

* `groups_file` ([`str`](https://docs.python.org/3/library/stdtypes.html#str)): Group ids from `/start` in a group are written
  here when polling stops.

* `join_token` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str)]): Token from `Team.issue_join_token`, when required.

* `instance_id` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str)]): Stable id for this running copy.

**Raises:**

* [`ValueError`](https://docs.python.org/3/library/exceptions.html#ValueError): No bot token was given and `TELEGRAM_BOT_TOKEN`
  is unset.

Inherits from [`AIAgent`](/api/prebuilt-ai_agent#agentconnect-prebuilt-ai-agent-aiagent).

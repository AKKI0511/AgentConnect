## `DirectoryEntry`

Full Profile and identity for one Team Membership.

`BaseAgent.get_entry` returns this record. The DID identifies the agent;
the Profile describes suitable work. Model-facing `get_profiles` returns
per-Address Profile items instead.

Inherits from [`SchemaModel`](/api/core-base#agentconnect-core-base-schemamodel).

## `FindRequest`

Find teammates by describing the work.

Ranked matches are candidates, not proof of suitability. Overlapping
Profiles need `get_profiles`. Reuse cards already read. You may
conclude nobody fits. Compact cards omit description; that text is
on the full Profile.

Inherits from [`SchemaModel`](/api/core-base#agentconnect-core-base-schemamodel).

<a id="agentconnect-core-directory-findrequest-query"></a>

### `query`

```python
query: str
```

Natural-language description of the work. Ranked matches are candidates, not proof that someone is suitable.

* `min_length`: `1`
* `max_length`: `1000`
* `pattern`: `'\\S'`

<a id="agentconnect-core-directory-findrequest-limit"></a>

### `limit`

```python
limit: Optional[JsonInt] = None
```

**Types:** [`JsonInt`](/api/core-base#agentconnect-core-base-jsonint).

Maximum matches from 1 to 100. Omit to receive every other member, at most 100.

* `ge`: `1`
* `le`: `100`

<a id="agentconnect-core-directory-findresult"></a>

## `FindResult`

Candidate matches, best first.

An empty list means no candidates were returned. Ranking does not prove
suitability; read a selected teammate's full Profile before assigning work.

Inherits from [`SchemaModel`](/api/core-base#agentconnect-core-base-schemamodel).

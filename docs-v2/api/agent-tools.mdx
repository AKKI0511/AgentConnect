### `from_callable` `classmethod`

```python
from_callable(
    fn: ToolHandler,
    *,
    name: str | None = None,
    description: str | None = None,
) -> Tool
```

Build a Tool from an annotated function and its docstring.

Parameter descriptions come from the function's `Args` section.
The first paragraph of the docstring becomes `description` unless
you pass one.

**Parameters:**

* `fn` ([`ToolHandler`](/api/agent-tools#agentconnect-agent-tools-toolhandler)): Async or sync callable. Each advertised argument needs a
  type annotation other than `Any`. Keyword-only and
  positional-or-keyword arguments are supported.

* `name` ([`str`](https://docs.python.org/3/library/stdtypes.html#str) | None): Tool name. Defaults to `fn.__name__`.

* `description` ([`str`](https://docs.python.org/3/library/stdtypes.html#str) | None): Tool description. Defaults to the docstring
  summary.

**Returns:**

* ([`Tool`](/api/agent-tools#agentconnect-agent-tools-tool)): A `Tool` whose `parameters` schema matches the signature.

**Raises:**

* [`ValueError`](https://docs.python.org/3/library/exceptions.html#ValueError): The signature cannot be advertised (`*args`,
  `**kwargs`, positional-only, missing annotation, or
  `Any`).

## `TeamTools`

The six Team tool descriptors for one Agent.

`BaseAgent.team_tools` returns this sequence. Iterate it and pass it
to a harness. Each `Tool.handler` returns JSON. `ask` and
`get_result` include `ticket_id`. An `open` result has no `content`.
A completed result has `content`.

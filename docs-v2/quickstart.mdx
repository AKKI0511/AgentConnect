A Team is the durable object. Start one, join an agent, then send work. The handler on this page returns a string so you can see a round trip without a model.

## Prerequisites

- Python 3.10 or newer
- [AgentConnect installed](/install)

## Start a Team and join an agent

<Steps>
  <Step title="Install">
    ```bash
    pip install agentconnect
    ```
  </Step>
  <Step title="Write a handler">
    Subclass `BaseAgent`, set a profile, and implement `handle`.

    ```python
    import asyncio

    from agentconnect import AgentProfile, BaseAgent, Context, MailboxMessage, Skill
    from agentconnect.team import Team

    class Writer(BaseAgent):
        profile = AgentProfile(
            summary="Writes short drafts from notes.",
            skills=[
                Skill(
                    name="drafting",
                    description="Turn notes into a two-paragraph draft.",
                )
            ],
        )

        async def handle(self, msg: MailboxMessage, ctx: Context) -> str | None:
            if msg.kind != "request":
                return None
            return f"Draft complete for {msg.content!r}."
    ```
  </Step>
  <Step title="Start the Team and join">
    ```python
    async def main() -> None:
        team = await Team("content-squad").start()
        await Writer(name="writer").join(team)

    asyncio.run(main())
    ```
  </Step>
</Steps>

| --- | --- |

## `RegistryAPISettings`

Registry API Server configuration loaded from environment variables only.

For System Operators deploying infrastructure. Environment variables must be prefixed
with AGENTCONNECT\_REGISTRY\_ to avoid collisions.

<a id="agentconnect-config-servers-registryapisettings-host"></a>

### `host`

```python
host: str = 'localhost'
```

Server host address. Use '0.0.0.0' to be accessible from outside a container.

Default: `'localhost'`.

<a id="agentconnect-config-servers-registryapisettings-port"></a>

### `port`

```python
port: int = 8000
```

Server port

Default: `8000`.

* `ge`: `1`
* `le`: `65535`

<a id="agentconnect-config-servers-registryapisettings-reload"></a>

### `reload`

```python
reload: bool = False
```

Enable Uvicorn's auto-reload on code changes (for development).

Default: `False`.

<a id="agentconnect-config-servers-registryapisettings-log-level"></a>

### `log_level`

```python
log_level: str = 'INFO'
```

Log level (DEBUG, INFO, WARNING, ERROR, CRITICAL)

Default: `'INFO'`.

<a id="agentconnect-config-servers-registryapisettings-allowed-origins"></a>

### `allowed_origins`

```python
allowed_origins: List[str]
```

CORS allowed origins

Default factory: `lambda: ['http://localhost:5173', 'http://localhost:3000']`.

<a id="agentconnect-config-servers-registryapisettings-vector-search"></a>

### `vector_search`

```python
vector_search: VectorSearchSettings
```

Vector search configuration for the underlying vector store

Default factory: [`VectorSearchSettings`](/api/config-vector#agentconnect-config-vector-vectorsearchsettings).

<a id="agentconnect-config-servers-registryapisettings-vector-search-json"></a>

### `vector_search_json`

```python
vector_search_json: Optional[str] = None
```

JSON override for vector\_search settings. When set, it overrides all nested vector\_search env keys.

Default: `None`.

<a id="agentconnect-config-servers-registryapisettings-settings-customise-sources"></a>

`staticmethod`

### `settings_customise_sources`

```python
settings_customise_sources(settings_cls: type[BaseSettings], init_settings: PydanticBaseSettingsSource, env_settings: PydanticBaseSettingsSource, dotenv_settings: PydanticBaseSettingsSource, file_secret_settings: PydanticBaseSettingsSource) -> tuple[PydanticBaseSettingsSource, ...]
```

Use a lenient env source to avoid hard JSON parsing for complex fields.

This ensures values like "a,b" for list fields don't raise during env parsing
and can be handled by our field validators instead.

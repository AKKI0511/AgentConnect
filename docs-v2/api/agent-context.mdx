Handler Context: delivery facts plus verbs to call teammates.

`handle` receives `(msg, ctx)`. `msg` is the delivered [`MailboxMessage`](/api/core-message#agentconnect-core-message-mailboxmessage).
`ctx` carries verified facts about this Delivery plus `ask`, `tell`,
`find`, `get_entry`, history paging, and `defer`.

Return a JSON value from `handle` to reply now. Return `None` to decline
a request, or to finish an event. Call `ctx.defer()` and return from
`handle` to answer later through the handle. After `defer()`, that return
value is not used as a reply.

**Examples:**

Inside `handle`, for a request. A bounded `ask` can return `open`:

```python
ticket = await ctx.ask("echo", msg.content)
if ticket.state == "completed":
    return ticket.content
return None
```

## `DeferredReply`

```python
DeferredReply(session: 'Session', delivery: Delivery)
```

Handle that finishes a reply-expected Delivery after `handle` returns.

Call `Context.defer()` to obtain this handle, then return from
`handle`. The Delivery stays leased until `reply`, `fail`, or
`decline` succeeds, or the lease expires and another Instance may
take it. The Session renews that lease until then, up to the request
deadline. The slot still counts toward `max_in_flight`.

**Examples:**

Defer, then complete later from a background task:

```python
from agentconnect.agent import DeferredReply

async def handle(self, msg, ctx):
    pending = ctx.defer()
    asyncio.create_task(self._finish(pending))
    return None

async def _finish(self, pending: DeferredReply) -> None:
    await pending.reply({"draft": "..."})
```

Hold the Session and Delivery this handle will finish.

Call `Context.defer()` instead of constructing this yourself.

## `Context`

```python
Context(session: 'Session', delivery: Delivery)
```

Facts about the current Delivery, plus verbs to talk to the Team.

The Session passes this into `handle`. When several Instances share
one Membership they pull one Mailbox. Working state that lives only
in this process is lost if another Instance handles the next turn.
Use `history` (and `get_history` for older turns) as the source of
conversation state.

Attach one leased Delivery. The Session constructs this for `handle`.

<a id="agentconnect-agent-context-context-defer"></a>

### `defer`

```python
defer() -> DeferredReply
```

Keep the Delivery leased and answer later.

Return from `handle` after calling this. The return value is not
used as a reply. Finish with `reply`, `fail`, or `decline` on the
handle. The Session renews the lease until that finish, the
request deadline, disconnect, or revocation. This still counts as
one in-flight Delivery.

**Returns:**

* ([`DeferredReply`](/api/agent-context#agentconnect-agent-context-deferredreply)): A handle for this leased Delivery. Calling `defer` again

* ([`DeferredReply`](/api/agent-context#agentconnect-agent-context-deferredreply)): returns the same object.

**Examples:**

```python
handle = ctx.defer()
asyncio.create_task(self._finish(handle))
return None
```

<a id="agentconnect-agent-context-context-ask"></a>

`async`

### `ask`

```python
ask(recipient: str, content: Any, *, deadline_seconds: Optional[float] = None, collect: CollectMode = 'wait', thread_id: Optional[str] = None, parent_id: Optional[str] = None, metadata: Optional[Mapping[str, Any]] = None) -> Ticket
```

Send a reply-expected request and collect the result.

Same send contract as [`BaseAgent.ask`](/api/agent-base#agentconnect-agent-base-baseagent-ask). From a handler this sets
`parent_id` to the current Message when you omit it. An omitted
deadline inherits that request's stamped cutoff. The Runtime
rejects a child that exceeds the parent. The send continues this
Thread when `recipient` is the other party and this Message
already has a thread. Otherwise a new Thread starts.

`collect="wait"` (default) holds until the Ticket is terminal or
the Runtime wait hold elapses, then returns the current Ticket.
That Ticket may still be `open`. Ending the wait does not cancel
accepted work. Read a completed reply as `ticket.response.content`
after checking `ticket.state`. Collect later with
[`BaseAgent.get_result`](/api/agent-base#agentconnect-agent-base-baseagent-get-result).

**Parameters:**

* `recipient` (`str`): Local name or same-Team qualified Address, for
  example `writer` or `writer@content-squad`.

* `content` (`Any`): The work, as text or JSON.

* `deadline_seconds` (`Optional[float]`): Work cutoff in seconds. Omit to inherit the
  parent request or the Runtime work lifetime. This is not
  how long this call waits.

* `collect` ([`CollectMode`](/api/core-primitives#agentconnect-core-primitives-collectmode)): `"wait"` (default) holds this call. `"ticket"`
  returns immediately. Neither cancels work.

* `thread_id` (`Optional[str]`): Continue this conversation with the same
  recipient. Omit to inherit or start as described above.

* `parent_id` (`Optional[str]`): Message this send answers. Omit to use the current
  Message.

* `metadata` (`Optional[Mapping[str, Any]]`): Optional JSON object stored on the Message.

**Returns:**

* ([`Ticket`](/api/core-ticket#agentconnect-core-ticket-ticket)): The current Ticket. It may still be `open` when a wait ends.

**Raises:**

* ([`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror)): The Agent has not joined, or the Runtime
  rejected the send. Branch on `code`.

**Examples:**

Wait, then read a completed reply from `handle`:

```python
ticket = await ctx.ask("editor", "tighten this draft")
if ticket.state == "completed":
    return ticket.response.content
```

Return immediately. Collect later with [`BaseAgent.get_result`](/api/agent-base#agentconnect-agent-base-baseagent-get-result).
That Ticket can still be `open`:

```python
pending = await ctx.ask("writer", "long job", collect="ticket")
ticket = await self.get_result(pending.id)
if ticket.state == "completed":
    return ticket.response.content
```

### `tell`

```python
tell(recipient: str, content: Any, *, thread_id: Optional[str] = None, parent_id: Optional[str] = None, metadata: Optional[Mapping[str, Any]] = None) -> AcceptedSendResult
```

Send an event. No Ticket is created.

Same send contract as [`BaseAgent.tell`](/api/agent-base#agentconnect-agent-base-baseagent-tell). From a handler this sets
`parent_id` to the current Message when you omit it. Acceptance
means the Runtime queued the event, not that the recipient
finished handling it.

**Parameters:**

* `recipient` (`str`): Local name or same-Team qualified Address.

* `content` (`Any`): The notice, as text or JSON.

* `thread_id` (`Optional[str]`): Continue this conversation with a current
  participant. Omit to inherit or start as `ask` does.

* `parent_id` (`Optional[str]`): Message this send answers. Omit to use the current
  Message.

* `metadata` (`Optional[Mapping[str, Any]]`): Optional JSON object stored on the Message.

**Returns:**

* ([`AcceptedSendResult`](/api/core-operations#agentconnect-core-operations-acceptedsendresult)): An acknowledgement that the event was accepted.

**Raises:**

* ([`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror)): The Agent has not joined, or the Runtime
  rejected the send.

**Examples:**

```python
await ctx.tell("writer", {"note": "source changed"})
```

`async`

### `find`

```python
find(query: str, *, limit: int | None = None) -> FindResult
```

Search this Team's Directory, excluding this Agent.

Light cards include Address, summary, Skill names, and Profile
tags. Ranked matches are candidates, not proof of suitability.
Call `get_entry` for one full Profile.

**Parameters:**

* `query` (`str`): Natural-language description of the work.

* `limit` (`int | None`): Maximum matches from 1 to 100. Omit to receive every
  other member, at most 100.

**Returns:**

* ([`FindResult`](/api/core-directory#agentconnect-core-directory-findresult)): Ranked matches, best first.

**Raises:**

* ([`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror)): The Agent has not joined.

**Examples:**

```python
found = await ctx.find("someone who can review a contract")
peer = found.matches[0].address
```

<a id="agentconnect-agent-context-context-get-history"></a>

`async`

### `get_history`

```python
get_history(*, before: Optional[str] = None, limit: int = 50) -> HistoryResult
```

Page retained history for this Delivery's Thread.

Omit `before` for the newest page. When `has_more` is true, pass
`next_before` as the next `before`. The newest page is first;
turns inside a page are oldest to newest. Returns empty history
when the Message has no `thread_id`.

**Parameters:**

* `before` (`Optional[str]`): Return Messages older than this id. Prefer
  `next_before` from the previous page.

* `limit` (`int`): Page size from 1 to 200. Defaults to 50.

**Returns:**

* ([`HistoryResult`](/api/core-operations#agentconnect-core-operations-historyresult)): One page. When `has_more` is true, pass `next_before` as

* ([`HistoryResult`](/api/core-operations#agentconnect-core-operations-historyresult)): the next `before`.

**Raises:**

* ([`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror)): The Agent has not joined, or is not a
  participant.

**Examples:**

```python
page = await ctx.get_history()
if page.has_more:
    older = await ctx.get_history(before=page.next_before)
```

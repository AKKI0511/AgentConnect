Runtime operations a Client uses to talk to a Team.

Session is a set of operations, not a wire format. In-process and HTTP
both implement this protocol so Agent code does not change between them.
Everyday Agent code uses [`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent), which calls these operations through
a Session transport.

## `TransportError`

```python
TransportError(code: str, message: str, *, details: Optional[dict[str, Any]] = None, retryable: Optional[bool] = None)
```

A Runtime operation failed with a public error code.

`code` matches the Runtime contract (for example `not_found`,
`busy`, `unavailable`). Branch on `code`, not on the exception
message.

**Attributes:**

* `code`: Public error code.

* `message`: Human-readable explanation.

* `details`: Optional extra fields from the Runtime.

* `retryable`: True when a later identical call may succeed.

Record the public error `code` and human-readable `message`.

**Parameters:**

* `code` (`str`): Public error code from the Runtime contract.

* `message` (`str`): Human-readable explanation.

* `details` (`Optional[dict[str, Any]]`): Optional extra fields.

* `retryable` (`Optional[bool]`): True when a later identical call may succeed.

## `RuntimeTransport`

One Client connection to a Runtime.

These token-taking methods are the Session transport. Everyday Agent
code uses [`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent), not these methods directly. Implementations
must not import [`agentconnect.agent`](/api/agent). In-process implementations must
not import [`agentconnect.team`](/api/team); they call methods on a duck-typed
Runtime object supplied by the caller.

## `TeamError`

```python
TeamError(code: str, message: str, *, details: Optional[dict[str, Any]] = None, retryable: Optional[bool] = None)
```

A Runtime operation failed with a public error code.

`code` is one of the well-known codes in the AgentConnect Runtime
contract (for example `not_found`, `busy`, `wait_limit`,
`id_conflict`). Branch on `code`, not on the exception message.

**Attributes:**

* `code`: Public error code.

* `message`: Human-readable explanation.

* `details`: Optional extra fields from the Runtime.

* `retryable`: True when a later identical call may succeed.

Set the public `code` and `message` for this failure.

**Parameters:**

* `code` (`str`): Public error code from the Runtime contract.

* `message` (`str`): Human-readable explanation.

* `details` (`Optional[dict[str, Any]]`): Optional extra fields.

* `retryable` (`Optional[bool]`): True when a later identical call may succeed.

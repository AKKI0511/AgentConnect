Immutable Message kinds and Delivery.

A handler receives a [`MailboxMessage`](/api/core-message#agentconnect-core-message-mailboxmessage) (request or event) with attribute
access. A request always expects a reply and opens a Ticket, the
requester's durable record for that work. Fire-and-forget work is an
event. Response and error Messages are created by the Runtime on reply.

**Examples:**

Read fields on a delivered Message:

```python
msg.kind
msg.content
msg.sender_did
msg.deadline  # requests only
msg.seq  # present when the Message belongs to a Thread
```

## `MessageBase`

Fields shared by every accepted Message.

`id` is Client-proposed on `send` and `reply` and stored unchanged at
acceptance. The Runtime sets canonical Addresses (`name@team`),
`sender_did` (the sender's `did:key`), `created_at`, `trace_id`, and
`seq` when `thread_id` is present. `seq` is present exactly when
`thread_id` is present. History and `before` cursors order by `seq`,
not by `created_at`.

**Attributes:**

* `id` ([`Uuid`](/api/core-primitives#agentconnect-core-primitives-uuid)): Immutable Message id and idempotency key.

* `sender` ([`QualifiedAddress`](/api/core-primitives#agentconnect-core-primitives-qualifiedaddress)): Canonical qualified Address set by the Runtime.

* `sender_did` ([`AgentDid`](/api/core-primitives#agentconnect-core-primitives-agentdid)): Verified DID of the sending Membership, copied from
  the Session at acceptance.

* `recipient` ([`QualifiedAddress`](/api/core-primitives#agentconnect-core-primitives-qualifiedaddress)): Canonical qualified Address set by the Runtime.

* `created_at` ([`Timestamp`](/api/core-primitives#agentconnect-core-primitives-timestamp)): Runtime acceptance time.

* `trace_id` ([`Uuid`](/api/core-primitives#agentconnect-core-primitives-uuid)): Correlation id for one causal operation.

* `thread_id` (`Optional[Uuid]`): Conversation grouping id, when the Message has one.

* `parent_id` (`Optional[Uuid]`): Message this one replies to or continues.

* `seq` (`Optional[JsonInt]`): Position in the Thread, assigned on acceptance. Present
  exactly when `thread_id` is present. First Message is `1`.

Inherits from [`SchemaModel`](/api/core-base#agentconnect-core-base-schemamodel).

## `RequestMessage`

Request that always expects a reply and opens a Ticket.

`deadline` is required on an accepted request. Fire-and-forget work
is an `event`. A Ticket is the requester's durable record whose id
equals this Message id.

**Attributes:**

* `kind` (`Literal['request']`): Always `request`.

* `content` ([`JsonValue`](/api/core-base#agentconnect-core-base-jsonvalue)): Sender-controlled work input.

* `metadata` (`Optional[JsonObject]`): Sender-controlled application data. Never used for
  Runtime decisions.

* `deadline` ([`Timestamp`](/api/core-primitives#agentconnect-core-primitives-timestamp)): Absolute time after which an open Ticket expires.

**Examples:**

```python
msg.kind  # "request"
msg.deadline
msg.seq  # set when the Message belongs to a Thread
```

## `Delivery`

One exclusive attempt to handle a Message.

`history` is the bounded recent Thread window, ordered by `seq` and
excluding `message`. After `join(..., delivery_history="ids")`,
`history` is empty and `history_ids` lists those earlier ids.

**Attributes:**

* `lease_id` ([`Uuid`](/api/core-primitives#agentconnect-core-primitives-uuid)): Opaque id authorizing completion of this attempt.

* `lease_expires_at` ([`Timestamp`](/api/core-primitives#agentconnect-core-primitives-timestamp)): Time after which this attempt is no longer active.

* `attempt` (`JsonInt`): Starts at 1 and increases after recovery.

* `message` (`Union[RequestMessage, EventMessage]`): Request or event leased from the Membership's Mailbox.

* `history` (`list[Message]`): Bounded recent window of earlier Messages. Empty when
  the Session joined with `delivery_history="ids"`.

* `history_ids` (`Optional[list[Uuid]]`): Earlier Message ids when the Session joined with
  `delivery_history="ids"`. Omitted when the window is bodies.

* `history_complete` (`bool`): True when the delivered window already contains
  every earlier retained Message.

**Examples:**

```python
delivery.history
delivery.history_ids  # present only for ids mode
delivery.history_complete
```

Inherits from [`SchemaModel`](/api/core-base#agentconnect-core-base-schemamodel).

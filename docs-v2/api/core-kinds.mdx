## `MessageKind`

Kinds of accepted Message.

Requests expect a reply and open a Ticket. Events do neither. The Runtime
creates response or error Messages when a request is answered. Application
categories belong in content or metadata.

<a id="agentconnect-core-kinds-messagekind-request"></a>

### `REQUEST`

```python
REQUEST = 'request'
```

Work that expects a reply.

<a id="agentconnect-core-kinds-messagekind-response"></a>

### `RESPONSE`

```python
RESPONSE = 'response'
```

Successful reply to a request.

<a id="agentconnect-core-kinds-messagekind-error"></a>

### `ERROR`

```python
ERROR = 'error'
```

Failed reply to a request.

<a id="agentconnect-core-kinds-messagekind-event"></a>

### `EVENT`

```python
EVENT = 'event'
```

Information sent without a reply or Ticket.

Terminal human on a Team.

[`HumanAgent`](/api/prebuilt-human_agent#agentconnect-prebuilt-human-agent-humanagent) is a [`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent) that prints incoming work and reads a
reply from stdin. It needs the `cli` extra (`aioconsole`).

**Examples:**

```bash
pip install 'agentconnect[cli]'
```

```python
from agentconnect.prebuilt import HumanAgent, AIAgent
from agentconnect.team import Team

team = await Team("content-squad").start()
human = HumanAgent(name="operator-human")
assistant = AIAgent(name="assistant", model="gpt-4o-mini")
await human.join(team)
await assistant.join(team)
await human.start_interaction("assistant")
```

## `HumanAgent`

```python
HumanAgent(name: str, *, identity: Optional[AgentIdentity] = None, prompt: str = 'You: ', read_line: Optional[Callable[[str], Awaitable[str]]] = None, instance_id: Optional[str] = None, join_token: Optional[str] = None)
```

Person on a Team. Incoming work is printed; stdin is the reply.

**Examples:**

```python
human = HumanAgent(name="operator-human")
await human.join(team)
await human.start_interaction("assistant")
```

Create a human member. It has not joined a Team yet.

**Parameters:**

* `name` (`str`): Agent name, unique within the Team.

* `identity` (`Optional[AgentIdentity]`): Optional Agent identity. Omit to create one.

* `prompt` (`str`): Stdin prompt shown when a reply is needed.

* `read_line` (`Optional[Callable[[str], Awaitable[str]]]`): Optional async `(prompt) -> str`. Non-stdin UIs
  pass this instead of using the terminal.

* `instance_id` (`Optional[str]`): Stable id for this running copy.

* `join_token` (`Optional[str]`): Token from [`Team.issue_join_token`](/api/team-runtime#agentconnect-team-runtime-team-issue-join-token), when required.

Inherits from [`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent).

### `start_interaction`

```python
start_interaction(recipient: str) -> None
```

Read lines from stdin and `ask` `recipient` until exit.

Join a Team first. Type `exit` to stop.

**Parameters:**

* `recipient` (`str`): Directory name or Address of the peer Agent.

**Examples:**

```python
await human.start_interaction("assistant")
```

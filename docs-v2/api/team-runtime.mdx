## `Team`

```python
Team(
    name: str,
    *,
    store: Store | str | None = None,
    max_message_bytes: int = 1048576,
    max_mailbox_depth: int = 1000,
    delivery_history_limit: int = 50,
    wait_hold_seconds: float = 25.0,
    max_held_waits: int = 16,
    work_lifetime_seconds: float = 3600.0,
    max_deadline_seconds: float = 24 * 60 * 60,
    max_open_tickets: int = 1000,
    replay_horizon_seconds: float = 24 * 60 * 60,
    max_retained_bytes: int = 64 * 1024 * 1024,
    session_ttl_seconds: float = 300,
    lease_ttl_seconds: float = 60,
    thread_message_limit: int = 10000,
    max_instances: int = 100,
    max_join_challenges: int = 128,
    sweep_interval_seconds: float = 0.5,
    require_join_auth: bool = False,
    join_challenge_ttl_seconds: float = 60,
    join_token_ttl_seconds: float = 3600,
    embeddings: EmbeddingsArg = 'auto',
    tools: Sequence[Callable[..., object]] | None = None,
)
```

The group your agents join to find each other and exchange work.

Call `start` before agents join. As an async context manager, the
Team starts on entry and stops on exit. Agent instances stay in
your code.

Agents in this process join the object; use `serve` for a loopback
origin, or `create_runtime_app` on your server for other hosts.

Create a stopped Team.

**Parameters:**

* `name` ([`str`](https://docs.python.org/3/library/stdtypes.html#str)): A lowercase DNS label.

* `store` ([`Store`](/api/team-store-base#agentconnect-team-store-base-store) | [`str`](https://docs.python.org/3/library/stdtypes.html#str) | None): Omit for process memory, or pass a Redis URL such as
  `redis://127.0.0.1:6379/0` or a `Store`. Redis needs
  `agentconnect[redis]`. Use one Runtime with that URL.

* `max_message_bytes` ([`int`](https://docs.python.org/3/library/stdtypes.html#int)): UTF-8 JSON size cap for a Message or reply
  body. HTTP JSON bodies use the same cap.

* `max_mailbox_depth` ([`int`](https://docs.python.org/3/library/stdtypes.html#int)): Unleased items one mailbox may hold.
  Further sends fail with `busy`.

* `delivery_history_limit` ([`int`](https://docs.python.org/3/library/stdtypes.html#int)): Earlier Thread Messages included on a
  Delivery when `delivery_history` is `bodies`. Read older
  turns with `get_history`.

* `wait_hold_seconds` ([`float`](https://docs.python.org/3/library/stdtypes.html#float)): How long a `collect="wait"` send stays open.
  It then returns the current Ticket, which may still be open.
  Accepted work continues; collect it with `get_result`.

* `max_held_waits` ([`int`](https://docs.python.org/3/library/stdtypes.html#int)): Simultaneous `collect="wait"` sends per membership.
  Further waits fail with `wait_limit`.

* `work_lifetime_seconds` ([`float`](https://docs.python.org/3/library/stdtypes.html#float)): Cutoff for a new request that omitted
  `deadline` and has no request parent. The Team closes the
  request at this cutoff even if the agent is still working.
  Must be at least 1 and not exceed `max_deadline_seconds`.

* `max_deadline_seconds` ([`float`](https://docs.python.org/3/library/stdtypes.html#float)): Farthest a new request deadline may be from
  acceptance. Must be at least 1.

* `max_open_tickets` ([`int`](https://docs.python.org/3/library/stdtypes.html#int)): Open Tickets per requester membership.

* `replay_horizon_seconds` ([`float`](https://docs.python.org/3/library/stdtypes.html#float)): How long an identical send, reply, or
  complete returns the original result after the obligation
  ends. Must be at least 1.

* `max_retained_bytes` ([`int`](https://docs.python.org/3/library/stdtypes.html#int)): UTF-8 JSON size cap for retained Message
  bodies. Must be at least 1.

* `session_ttl_seconds` ([`float`](https://docs.python.org/3/library/stdtypes.html#float)): Idle Session lifetime, refreshed by heartbeat.

* `lease_ttl_seconds` ([`float`](https://docs.python.org/3/library/stdtypes.html#float)): Delivery lease lifetime between renewals.

* `thread_message_limit` ([`int`](https://docs.python.org/3/library/stdtypes.html#int)): Messages kept after no live Delivery or
  Ticket needs an older one.

* `max_instances` ([`int`](https://docs.python.org/3/library/stdtypes.html#int)): Running copies allowed per membership.

* `max_join_challenges` ([`int`](https://docs.python.org/3/library/stdtypes.html#int)): Unused join challenges allowed at once.

* `sweep_interval_seconds` ([`float`](https://docs.python.org/3/library/stdtypes.html#float)): Time between expiry passes for Sessions,
  leases, Tickets, and join credentials.

* `require_join_auth` ([`bool`](https://docs.python.org/3/library/functions.html#bool)): Require a join token and identity proof.

* `join_challenge_ttl_seconds` ([`float`](https://docs.python.org/3/library/stdtypes.html#float)): Lifetime of an unused join challenge.

  `agentconnect.team.directory` for choices. A backend failure

* `tools` ([`Sequence`](https://docs.python.org/3/library/collections.abc.html#collections.abc.Sequence)\[[`Callable`](https://docs.python.org/3/library/collections.abc.html#collections.abc.Callable)\[..., [`object`](https://docs.python.org/3/library/functions.html#object)]] | None): Extra MCP tools beside the reserved Team tools.

<a id="agentconnect-team-runtime-team-start"></a>

### `start`

<p className="ac-symbol-meta">async</p>
```python
start() -> 'Team'
```

**Types:** [`Team`](/api/team-runtime#agentconnect-team-runtime-team).

Open the store and accept joins.

Calling this again on a started Team is safe. Invalid store values
raise `ValueError`; backend errors propagate.

**Examples:**

In an async function, `writer` and `researcher` are existing
agents. `writer` answers requests. `ask` waits for that reply.
Leave each agent and stop the Team after the reply is
complete. Keep the Team running while a Ticket you still need
is open.

```python
from agentconnect.team import Team

team = await Team("content-squad").start()
await writer.join(team)
await researcher.join(team)
ticket = await researcher.ask(
    "writer",
    "Draft a release note from these findings: search is faster.",
)
if ticket.state == "completed":
    print(ticket.content)
    await researcher.leave()
    await writer.leave()
    await team.stop()
```

<a id="agentconnect-team-runtime-team-serve"></a>

### `serve`

<p className="ac-symbol-meta">async</p>
```python
serve(host: str = '127.0.0.1', port: int = 0) -> str
```

Listen on loopback and return the origin agents join.

Pass the origin to `BaseAgent.join`; Team MCP is at `mcp_url`.
Issue a join token separately for a URL join. Attach MCP, or
`BaseAgent.team_tools`, in the harness yourself.

Install `agentconnect[serve]` first. An already-serving Team returns
its current origin. Agents on other hosts need `create_runtime_app`
on your server.

A request with no Authorization or forwarded-client headers runs
as the operator membership. See `create_runtime_app` for Session
authorization. A join token is only for `BaseAgent.join`.

**Parameters:**

* `host` ([`str`](https://docs.python.org/3/library/stdtypes.html#str)): Must be loopback.

* `port` ([`int`](https://docs.python.org/3/library/stdtypes.html#int)): Zero lets the OS choose a port.

**Raises:**

* [`TeamError`](/api/team-errors#agentconnect-team-errors-teamerror): Non-loopback host (`invalid_request`), missing serve
  extra, or listener startup failure (`unavailable`).

**Examples:**

In an async application, `team` is already started with
`require_join_auth=True`, and `writer` is an existing agent.

```python
origin = await team.serve()
issued = await team.issue_join_token(
    name=writer.name,
    agent_did=writer.agent_did,
    single_use=True,
)
await writer.join(origin, join_token=issued.token)
```

<a id="agentconnect-team-runtime-team-issue-join-token"></a>

### `issue_join_token`

<p className="ac-symbol-meta">async</p>
```python
issue_join_token(
    *,
    agent_did: str | None = None,
    name: str | None = None,
    ttl_seconds: float | None = None,
    single_use: bool = False,
) -> JoinTokenIssued
```

**Types:** [`JoinTokenIssued`](/api/core-operations#agentconnect-core-operations-jointokenissued).

Issue a join token for an agent that will join by URL.

Bind `name`, `agent_did`, or both. The join must match every
bound value. Omit both when any agent that can prove its identity
may use the token. `BaseAgent.join` on this Team object mints its
own token when `require_join_auth` is set and the agent has none.
Use this method for a token you pass into a URL join.

Omitting `ttl_seconds` uses `join_token_ttl_seconds`.

`single_use=True` admits one name and DID. That membership can
reconnect with the same token. Any other agent is rejected with
`unauthorized`. After `expires_at`, join fails with
`unauthorized`. Keep `token` out of logs and Messages. Pass it to
`BaseAgent.join`. After that join, HTTP calls use the Session
bearer from the join result.

**Raises:**

* [`TeamError`](/api/team-errors#agentconnect-team-errors-teamerror): The Team has not been started, with `code`
  `unavailable`. `name` or `agent_did` is invalid, or
  `ttl_seconds` is not positive, with `code`
  `invalid_request`.

### `join`

<p className="ac-symbol-meta">async</p>
```python
join(
    name: str | None = None,
    agent_did: str | None = None,
    profile: AgentProfile | Mapping[str, object] | None = None,
    *,
    spec_version: str = '1.0.0-draft',
    instance_id: str | None = None,
    max_in_flight: int = 1,
    join_token: str | None = None,
```

**Types:** [`DeliveryHistoryForm`](/api/core-primitives#agentconnect-core-primitives-deliveryhistoryform), [`JoinResult`](/api/core-operations#agentconnect-core-operations-joinresult).

Create or reconnect a Membership and open a Session.

Agent code uses `BaseAgent.join`. Authentication is optional when
`require_join_auth=False`; otherwise supply both `join_token` and

even when authentication is optional.

reconnects to that Membership; after removal, the same spelling is a
new Membership. Other clashes fail with `name_conflict`.

* `instance_id` ([`str`](https://docs.python.org/3/library/stdtypes.html#str) | None): UUID for this running copy; omit to generate one.

* `max_in_flight` ([`int`](https://docs.python.org/3/library/stdtypes.html#int)): Simultaneous Deliveries per Session, from 1 to 100.

* `request` ([`JoinRequest`](/api/core-operations#agentconnect-core-operations-joinrequest) | [`Mapping`](https://docs.python.org/3/library/collections.abc.html#collections.abc.Mapping)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str), [`object`](https://docs.python.org/3/library/functions.html#object)] | None): `JoinRequest` or raw mapping supplying the join arguments.

<a id="agentconnect-team-runtime-team-send"></a>

### `send`

<p className="ac-symbol-meta">async</p>
```python
send(session_token: str, request: SendRequest | Mapping[str, object]) -> SendResult
```

**Types:** [`SendResult`](/api/core-operations#agentconnect-core-operations-sendresult).

Accept one request or event for one recipient in this Team.

Agent code uses `BaseAgent.ask` or `BaseAgent.tell`.

The Message, Ticket, Thread append, and Mailbox enqueue commit
together. A recipient cannot lease the item until that commit
finishes. `collect="wait"` holds until the Ticket is terminal or
`wait_hold_seconds` elapses, then returns the current Ticket.
Ending the wait does not cancel work; collect the rest with
`get_result`.

Repeating the same ID and send data returns the original result
within the replay horizon. Changing data under that ID fails with
`id_conflict`. Reuse the ID after an uncertain network outcome.

**Parameters:**

* `session_token` ([`str`](https://docs.python.org/3/library/stdtypes.html#str)): Credential from `join`.

* `request` ([`SendRequest`](/api/core-operations#agentconnect-core-operations-sendrequest) | [`Mapping`](https://docs.python.org/3/library/collections.abc.html#collections.abc.Mapping)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str), [`object`](https://docs.python.org/3/library/functions.html#object)]): Send body. Required keys are `id` (client-generated
  UUID, becomes the Message id), `recipient` (Agent name or
  Address), `kind` (`"request"` or `"event"`), and
  `content` (JSON). A request also needs `collect`
  (`"wait"` or `"ticket"`). `deadline` may be omitted; the
  Runtime stamps `work_lifetime_seconds` or inherits a
  request parent's cutoff. An event must omit `collect`
  and `deadline`.

Requests return `status="ticketed"` with a Ticket; events return
`status="accepted"` with no `ticket` attribute.

**Raises:**

* [`TeamError`](/api/team-errors#agentconnect-team-errors-teamerror): The Session is missing (`unauthorized`), the body
  is invalid (`invalid_request`, `invalid_address`,
  `address_outside_team`, `payload_too_large`), the
  recipient or parent is missing (`not_found`), the
  Mailbox is full (`busy`), too many waits are held
  (`wait_limit`), the ID was reused for different data
  (`id_conflict`), or the Team has not been started
  (`unavailable`).

**Examples:**

For a started `team`, `session_token` from a requester join,
and a joined `writer` membership. `message_id` is a new UUID
string. Save the Ticket ID to collect this work later:

```python
result = await team.send(
    session_token,
    {
        "id": message_id,
        "recipient": "writer",
        "kind": "request",
        "content": {"task": "draft"},
        "collect": "ticket",
    },
)
if result.status == "ticketed":
    ticket_id = result.ticket.id
```

```python
lease(session_token: str, max_items: int = 1) -> LeaseResult
```

`BaseAgent` leases for the handler. Each Delivery must be finished with `reply` or `complete` before the

<a id="agentconnect-team-runtime-team-complete"></a>

### `complete`

<p className="ac-symbol-meta">async</p>
```python
complete(session_token: str, lease_id: str) -> CompleteResult
```

Finish a Delivery without a response Message.

`BaseAgent` maps a `None` handler return onto this call. An event just ends. A request is declined: the Ticket
becomes `declined`, which is not a failure.

Repeating a successful completion returns its original result
within the replay horizon.

**Returns:**

* ([`CompleteResult`](/api/core-operations#agentconnect-core-operations-completeresult)): `ticket` is None for an event. Serialization omits that field.

**Raises:**

* [`TeamError`](/api/team-errors#agentconnect-team-errors-teamerror): The Session is missing (`unauthorized`),
  `lease_id` is invalid (`invalid_request` or `not_found`),
  the lease is no longer active (`lease_expired`), or the
  Ticket is already terminal (`ticket_closed`).

<a id="agentconnect-team-runtime-team-reply"></a>

### `reply`

<p className="ac-symbol-meta">async</p>
```python
reply(session_token: str, request: ReplyRequest | Mapping[str, object]) -> ReplyResult
```

**Types:** [`ReplyResult`](/api/core-operations#agentconnect-core-operations-replyresult).

Finish a reply-expected Delivery with content or an error.

`BaseAgent` maps a handler return onto this call. Valid only for a request. The response Message, Ticket,
Thread append, and lease acknowledgement commit together. A body
larger than `max_message_bytes` fails with `payload_too_large`
and leaves the Ticket `open` and the lease active.

Repeating the same reply ID, target request, and outcome data
returns the original result within the replay horizon. Different
data under that ID fails with `id_conflict`. The lease still has
to belong to the calling membership.

**Parameters:**

* `session_token` ([`str`](https://docs.python.org/3/library/stdtypes.html#str)): Live Session token from `join`.

* `request` ([`ReplyRequest`](/api/core-operations#agentconnect-core-operations-replyrequest) | [`Mapping`](https://docs.python.org/3/library/collections.abc.html#collections.abc.Mapping)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str), [`object`](https://docs.python.org/3/library/functions.html#object)]): Reply body. Required keys are `id` (client-generated
  UUID), `lease_id`, and `outcome` (`"completed"` or
  `"failed"`). Completed replies need `content`. Failed
  replies need `error` (`code` and `message`).

**Raises:**

* [`TeamError`](/api/team-errors#agentconnect-team-errors-teamerror): The Session is missing (`unauthorized`), the body
  is invalid (`invalid_request` or `payload_too_large`),
  the reply ID has different data (`id_conflict`),
  the lease is missing (`not_found`), the lease is no
  longer active (`lease_expired`), or the Ticket is already
  terminal (`ticket_closed`).

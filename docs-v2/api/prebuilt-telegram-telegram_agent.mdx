Telegram bot that is also an [`AIAgent`](/api/prebuilt-ai_agent#agentconnect-prebuilt-ai-agent-aiagent).

Join a Team like any other Agent, then `run()` to poll Telegram. Incoming
Telegram text goes through the same LiteLLM loop as Team work. Telegram
operations are extra tools.

**Examples:**

For a started Team. Close the Session with `leave` when finished:

```python
from agentconnect.prebuilt import TelegramAIAgent

agent = TelegramAIAgent(
    name="telegram-bot",
    model="gpt-4o-mini",
    telegram_token="...",
)
await agent.join(team)
```

## `TelegramAIAgent`

```python
TelegramAIAgent(name: str, *, model: str, telegram_token: Optional[str] = None, instructions: str = 'You are a helpful Telegram assistant.', tools: Optional[Sequence[ToolLike]] = None, identity: Optional[AgentIdentity] = None, profile: AgentProfile | Mapping[str, object] | None = None, completion: Optional[CompletionOptions] = None, api_key: Optional[str] = None, complete: Optional[CompletionFn] = None, max_tool_rounds: int = 8, include_team_tools: bool = True, groups_file: str = 'groups.txt', join_token: Optional[str] = None, instance_id: Optional[str] = None)
```

[`AIAgent`](/api/prebuilt-ai_agent#agentconnect-prebuilt-ai-agent-aiagent) with a Telegram bot. Team deliveries use `handle`.

Join a Team first if teammates should reach you, then `run()` to poll.

**Examples:**

For a started Team:

```python
agent = TelegramAIAgent(name="telegram-bot", model="gpt-4o-mini")
await agent.join(team)
```

Create a Telegram-backed Agent. It has not joined a Team or started polling.

**Parameters:**

* `name` (`str`): Agent name, unique within the Team.

* `model` (`str`): LiteLLM model id.

* `telegram_token` (`Optional[str]`): BotFather token. `TELEGRAM_BOT_TOKEN` is used
  when this is omitted.

* `instructions` (`str`): System prompt for every model call.

* `tools` (`Optional[Sequence[ToolLike]]`): Extra tools besides Telegram tools and Session Team tools.

* `identity` (`Optional[AgentIdentity]`): Optional Agent identity. Omit to create one.

* `profile` (`AgentProfile | Mapping[str, object] | None`): Discovery Profile mapping or [`AgentProfile`](/api/core-profile#agentconnect-core-profile-agentprofile).

* `completion` (`Optional[CompletionOptions]`): Extra LiteLLM kwargs such as `temperature`.

* `api_key` (`Optional[str]`): Optional key. LiteLLM also reads provider env vars.

* `complete` (`Optional[CompletionFn]`): Replace LiteLLM with another async callable of the
  same shape.

* `max_tool_rounds` (`int`): Cap on model-tool-model cycles per turn.

* `include_team_tools` (`bool`): When True (default), Session Team tools are
  attached on Team turns and Telegram replies.

* `groups_file` (`str`): Path used to remember registered group chat ids.

* `join_token` (`Optional[str]`): Token from [`Team.issue_join_token`](/api/team-runtime#agentconnect-team-runtime-team-issue-join-token), when required.

* `instance_id` (`Optional[str]`): Stable id for this running copy.

**Raises:**

* (`ValueError`): No bot token was given and `TELEGRAM_BOT_TOKEN`
  is unset.

Inherits from [`AIAgent`](/api/prebuilt-ai_agent#agentconnect-prebuilt-ai-agent-aiagent).

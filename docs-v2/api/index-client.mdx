HTTP client for the optional published-directory Index.

[`RegistryAPIClient`](/api/index-client#agentconnect-index-client-registryapiclient) talks to an Index process over HTTP. Use it to
register published Agents and search across Teams you did not configure
locally. Same-Team discovery uses [`BaseAgent.find`](/api/agent-base#agentconnect-agent-base-baseagent-find), not this client.

Default origin is `http://localhost:8000`. Pass `base_url` to target
another Index. Close the client with `close` or use it as an async
context manager.

**Examples:**

The Index process must already be up:

```python
from agentconnect.index import RegistryAPIClient

async with RegistryAPIClient(base_url="http://127.0.0.1:8000") as client:
    agents = await client.get_all_agents()
    len(agents)
```

## `RegistryAPIClient`

```python
RegistryAPIClient(base_url: Optional[str] = None, timeout: Optional[float] = None, connect_timeout: Optional[float] = None, read_timeout: Optional[float] = None, pool_timeout: Optional[float] = None, max_connections: Optional[int] = None, max_keepalive_connections: Optional[int] = None)
```

HTTP client for one Index origin.

Construct with `base_url`, then `register`, `get_all_agents`, or
`get_by_capability_semantic`. Timeouts are seconds. Omitted values
use the client defaults (30s request, 10s connect). Retry on 502,
503, and 504 up to three times.

Open an HTTP client for one Index origin.

**Parameters:**

* `base_url` (`Optional[str]`): Index origin, for example `http://127.0.0.1:8000`.
  Defaults to `http://localhost:8000`.

* `timeout` (`Optional[float]`): Default request timeout in seconds. Defaults to 30.

* `connect_timeout` (`Optional[float]`): Connect timeout in seconds. Defaults to 10.

* `read_timeout` (`Optional[float]`): Read timeout in seconds. Defaults to 30.

* `pool_timeout` (`Optional[float]`): How long to wait for a pooled connection, in
  seconds. Defaults to 5.

* `max_connections` (`Optional[int]`): Connection pool size. Defaults to 10.

* `max_keepalive_connections` (`Optional[int]`): Keep-alive pool size. Defaults to 5.

**Raises:**

* (`ValueError`): `base_url` is missing after defaults.

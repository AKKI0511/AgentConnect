Session transports: how an Agent talks to its Team Runtime.

A Session is a set of operations (join, lease, reply, heartbeat), not a
wire format. [`InProcessTransport`](/api/transport-inprocess#agentconnect-transport-inprocess-inprocesstransport) is used when [`BaseAgent.join`](/api/agent-base#agentconnect-agent-base-baseagent-join) receives
a started [`Team`](/api/team-runtime#agentconnect-team-runtime-team). [`HttpRuntimeTransport`](/api/transport-agent_http#agentconnect-transport-agent-http-httpruntimetransport) is used when it receives a URL.
Agent code does not change between them.

[`RuntimeTransport`](/api/transport-runtime#agentconnect-transport-runtime-runtimetransport) is the protocol a custom transport implements.
[`TransportError`](/api/transport-runtime#agentconnect-transport-runtime-transporterror) is a failed Runtime operation; branch on `code`.

Tickets are stored on the Team. A dropped connection does not cancel
accepted work. Rejoin with the same `instance_id` and collect with
`get_result`.

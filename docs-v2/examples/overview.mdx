Recipes are copyable, not conceptual. Each page should run. Until the `examples/` projects are mirrored here, these pages hold the layout and a realistic stub.

| Recipe | Shows |
| --- | --- |
| [Minimal team](/examples/minimal-team) | Start, join, one handler |
| [Request and reply](/examples/request-reply) | `ask`, ticket states, collect modes |
| [Directory search](/examples/directory-search) | Rank profiles and route a request |

<AccordionGroup>
  <Accordion title="When to write a recipe instead of a guide">
    Write a recipe when the reader should paste code. Write a guide when the reader needs a decision, a constraint, or an order of operations that is not obvious from the snippet.
  </Accordion>
  <Accordion title="Where the runnable projects live">
    Standalone uv projects stay under repository `examples/`. This tab is the documented form of those projects, not a second copy of the source tree.
  </Accordion>
</AccordionGroup>

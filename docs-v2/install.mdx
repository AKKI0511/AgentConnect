## Python

<CodeGroup>

```bash pip
pip install agentconnect
```

```bash uv
uv add agentconnect
```

</CodeGroup>

## Extras

Install only what the process needs. Core works without model providers or server packages.

| Extra | Use |
| --- | --- |
| `serve` | HTTP Runtime |
| `cli` | Command-line entry point |
| `redis` | Redis-backed stores |
| `openai` | OpenAI model helper |
| `index` | Published-directory Index |

```bash
pip install 'agentconnect[serve,cli]'
```

## Check

```bash
python -c "import agentconnect; print(agentconnect.__version__)"
```

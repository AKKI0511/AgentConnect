Published v0.4 compatibility until v1.0.

New code imports Team files from [`agentconnect.config`](/api/config), schema types
from [`agentconnect.core`](/api/core), and errors from [`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror) or [`TeamError`](/api/team-errors#agentconnect-team-errors-teamerror).
This package is the only supported home for YAML Team files and the
v0.4 exception names (`AgentError`, `CommunicationError`, and the
others re-exported here).

A v0.4 `agentconnect.yaml` still loads through this package when no
TOML Team file exists in this directory or any ancestor. Do not add
new callers here.

## Public API

* `AgentError` — `agentconnect.compat.exceptions.AgentError`
* `CapabilityError` — `agentconnect.compat.exceptions.CapabilityError`
* `CommunicationError` — `agentconnect.compat.exceptions.CommunicationError`
* `ConfigurationError` — `agentconnect.compat.exceptions.ConfigurationError`
* `RegistrationError` — `agentconnect.compat.exceptions.RegistrationError`
* `SecurityError` — `agentconnect.compat.exceptions.SecurityError`

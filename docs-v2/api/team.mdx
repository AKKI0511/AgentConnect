Team Runtime: one named Team's membership, mailboxes, tickets, and directory.

[`Team`](/api/team-runtime#agentconnect-team-runtime-team) is a Runtime object in this process. It never holds Agent
objects. Agents pull work through a Session: they may join the same
process (embedded), be constructed by `agentconnect up` from a Team
file (hosted), or join a served origin by URL (independent).

Construct `Team("name")`, then `start`. Embedded joins omit credentials
unless you set `require_join_auth=True`. `serve` binds loopback HTTP and
mounts Team MCP at `{origin}/mcp`. For authenticated or non-loopback
serving, pass the started Team to
[`agentconnect.team.http.create_runtime_app`](/api/team-http#agentconnect-team-http-create-runtime-app) and run that app yourself.

`store="memory"` (default) is process-local. Pass a Redis URL when
memberships, mailboxes, open Tickets, and Thread history must survive a
Runtime restart. Shared Redis does not make extra Runtime replicas safe.

[`TeamError`](/api/team-errors#agentconnect-team-errors-teamerror) is the public failure from a Runtime operation. Branch on
`code`. Token-taking methods on [`Team`](/api/team-runtime#agentconnect-team-runtime-team) (`send`, `lease`, `reply`, …)
are the Session transport that HTTP, MCP, and the in-process Session
call by name. Agent code uses [`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent).

Hosting extensions:

* [`agentconnect.team.http.create_runtime_app`](/api/team-http#agentconnect-team-http-create-runtime-app) returns the ASGI app
* [`agentconnect.team.store`](/api/team-store) provides [`MemoryStore`](/api/team-store-memory#agentconnect-team-store-memory-memorystore), [`RedisStore`](/api/team-store-redis#agentconnect-team-store-redis-redisstore), and a custom [`Store`](/api/team-store-base#agentconnect-team-store-base-store)
* [`agentconnect.team.directory`](/api/team-directory) is the member Directory and embedders

**Examples:**

For a started Team with `require_join_auth=True` and a constructed
Agent. Close the Session with `leave` when finished:

```python
url = await team.serve()
issued = await team.issue_join_token(
    name=agent.name, agent_did=agent.agent_did
)
await agent.join(url, join_token=issued.token)
```

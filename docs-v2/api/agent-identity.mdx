Filesystem persistence for Agent identities.

`BaseAgent(identity_path=...)` loads or creates the key file. Callers
that already hold an `AgentIdentity` can use the same JSON helpers.

The file includes the private key. Anyone who can read it can
impersonate the Agent.

**Examples:**

Persist a key, then reuse it on the next process:

```python
from agentconnect.agent.identity import load_or_create_identity, save_identity

identity = load_or_create_identity("researcher.json")
save_identity(identity, "researcher-backup.json")
```

## `save_identity`

```python
save_identity(identity: AgentIdentity, path: str | Path) -> None
```

Write `identity`, including the private key, to `path`.

Creates parent directories when they are missing. The file is JSON.
On POSIX the file mode is set to `0o600` when the OS allows it.

**Parameters:**

* `identity` ([`AgentIdentity`](/api/core-identity#agentconnect-core-identity-agentidentity)): Key pair to store. Must include the private key.

* `path` ([`str`](https://docs.python.org/3/library/stdtypes.html#str) | [`Path`](https://docs.python.org/3/library/pathlib.html#pathlib.Path)): Destination file. Relative to the current directory, or
  absolute.

**Raises:**

* [`ValueError`](https://docs.python.org/3/library/exceptions.html#ValueError): `identity` has no private key, or its DID does not
  match the public key. The file is not written.

* [`OSError`](https://docs.python.org/3/library/exceptions.html#OSError): The file or a parent directory cannot be created or
  written.

**Examples:**

```python
from agentconnect import AgentIdentity
from agentconnect.agent.identity import save_identity

identity = AgentIdentity.create_key_based()
save_identity(identity, "researcher.json")
```

## `load_identity`

```python
load_identity(path: str | Path) -> AgentIdentity
```

Read an identity previously written by `save_identity`.

**Parameters:**

* `path` ([`str`](https://docs.python.org/3/library/stdtypes.html#str) | [`Path`](https://docs.python.org/3/library/pathlib.html#pathlib.Path)): JSON file created by `save_identity` or
  `load_or_create_identity`.

**Returns:**

* ([`AgentIdentity`](/api/core-identity#agentconnect-core-identity-agentidentity)): The stored key pair, including the private key.

**Raises:**

* [`ValueError`](https://docs.python.org/3/library/exceptions.html#ValueError): The file is missing, not JSON, missing the private
  key, or the DID does not match the public key.

**Examples:**

```python
from agentconnect.agent.identity import load_identity

identity = load_identity("researcher.json")
```

## `load_or_create_identity`

```python
load_or_create_identity(path: str | Path) -> AgentIdentity
```

Load `path` when it exists, otherwise mint a key and save it.

Restarting an Agent with the same path keeps the same DID. An
existing file that cannot be loaded raises `ValueError`. It is not
replaced.

**Parameters:**

* `path` ([`str`](https://docs.python.org/3/library/stdtypes.html#str) | [`Path`](https://docs.python.org/3/library/pathlib.html#pathlib.Path)): JSON file to load or create.

**Returns:**

* ([`AgentIdentity`](/api/core-identity#agentconnect-core-identity-agentidentity)): The stored or newly minted key pair.

**Raises:**

* [`ValueError`](https://docs.python.org/3/library/exceptions.html#ValueError): `path` exists but is not a valid identity file.

* [`OSError`](https://docs.python.org/3/library/exceptions.html#OSError): A new file cannot be written.

**Examples:**

```python
from agentconnect.agent.identity import load_or_create_identity

identity = load_or_create_identity("researcher.json")
```

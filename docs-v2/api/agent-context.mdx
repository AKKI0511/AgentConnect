## `Context`

Inspect the incoming Message and contact teammates while handling it.

`handle` receives this object. Use `sender` to identify the teammate,
`history` to read recent conversation Messages, and `ask` or `tell`
to send related work. `get_history` reads older conversation turns.

<a id="agentconnect-agent-context-context-defer"></a>

### `defer`

```python
defer() -> DeferredReply
```

Keep this Delivery leased and answer after `handle` returns.

Return from `handle` after this call; its return value is ignored.
Give the returned `DeferredReply` to your existing completion
workflow, which must finish it with `reply`, `fail`, or `decline`.

**Returns:**

* ([`DeferredReply`](/api/agent-context#agentconnect-agent-context-deferredreply)): The handle for this Delivery. Another `defer` call returns the same object.

**Examples:**

Within an existing request handler, `ctx` is the incoming
delivery's Context. Save the handle for your completion workflow.

```python
pending = ctx.defer()
```

In that workflow's async completion callback, `pending` is
the saved handle and `draft` is the finished result.

```python
await pending.reply(draft)
```

<a id="agentconnect-agent-context-context-ask"></a>

### `ask`

<p className="ac-symbol-meta">async</p>
```python
ask(
    recipient: str,
    content: JsonValue,
    *,
    deadline_seconds: Optional[float] = None,
    collect: CollectMode = 'wait',
    thread_id: Optional[str] = None,
    parent_id: Optional[str] = None,
    metadata: Optional[Mapping[str, JsonValue]] = None,
) -> Ticket
```

Send a request from `handle` and return a `Ticket`.

The returned Ticket may still be `open`. Accepted work keeps
running after this call returns.

Read `content` only when `state` is `completed`. Call
`BaseAgent.get_result` with `id` while `state` is `open`.
An open child does not finish the incoming request. Returning
`None` from `handle` declines it. Use `defer` if your handler
must return before it can reply.

**Parameters:**

* `recipient` ([`str`](https://docs.python.org/3/library/stdtypes.html#str)): Local name or same-Team Address, such as `writer`
  or `writer@content-squad`.

* `content` ([`JsonValue`](/api/core-base#agentconnect-core-base-jsonvalue)): The work, as text or JSON.

* `deadline_seconds` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`float`](https://docs.python.org/3/library/stdtypes.html#float)]): Work cutoff in seconds. This does not change
  how long `collect="wait"` waits. Omit it to inherit the
  parent request deadline. The Team rejects a later child
  deadline.

* `collect` ([`CollectMode`](/api/core-primitives#agentconnect-core-primitives-collectmode)): `wait` waits until the Ticket is terminal or
  `wait_hold_seconds` elapses. `ticket` returns the current
  Ticket without waiting.

* `thread_id` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str)]): Thread to continue with the same recipient. Omit it
  to continue the current Thread when `recipient` is the
  sender and this Message has a `thread_id`. Otherwise a
  new Thread starts.

* `parent_id` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str)]): Message this request answers. Omit it to use the
  current Message id.

* `metadata` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`Mapping`](https://docs.python.org/3/library/collections.abc.html#collections.abc.Mapping)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str), [`JsonValue`](/api/core-base#agentconnect-core-base-jsonvalue)]]): JSON object stored on the Message. Omit to store none.

**Returns:**

* ([`Ticket`](/api/core-ticket#agentconnect-core-ticket-ticket)): The current Ticket. It can still be `open`.

**Raises:**

* [`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror): The Agent has not joined, or the Team rejected
  the send. Read `code`.

**Examples:**

Within an existing handler, `ctx` belongs to the incoming
request and `draft` is text to review. This fragment inspects
a child Ticket; the handler still needs to finish its
incoming request.

```python
ticket = await ctx.ask(
    "editor",
    {"task": "Check for unsupported claims.", "draft": draft},
    collect="ticket",
)
if ticket.state == "completed":
    print(ticket.content)
```

### `tell`

<p className="ac-symbol-meta">async</p>
```python
tell(
    recipient: str,
    content: JsonValue,
    *,
    thread_id: Optional[str] = None,
    parent_id: Optional[str] = None,
    metadata: Optional[Mapping[str, JsonValue]] = None,
) -> AcceptedSendResult
```

Send a notice from `handle`. No Ticket is created.

Acceptance means the Team queued the event. It does not mean the
recipient finished handling it. Omit `parent_id` to use the
current Message id. Omit `thread_id` to continue or start a
Thread by the same rule as `ask`.

**Parameters:**

* `recipient` ([`str`](https://docs.python.org/3/library/stdtypes.html#str)): Local name or same-Team Address.

* `content` ([`JsonValue`](/api/core-base#agentconnect-core-base-jsonvalue)): The notice, as text or JSON.

* `thread_id` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str)]): Thread to continue with a current participant.
  Omit it to continue or start a Thread by the same rule
  as `ask`.

* `parent_id` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str)]): Message this notice answers. Omit it to use the
  current Message id.

* `metadata` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`Mapping`](https://docs.python.org/3/library/collections.abc.html#collections.abc.Mapping)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str), [`JsonValue`](/api/core-base#agentconnect-core-base-jsonvalue)]]): JSON object stored on the Message. Omit to store none.

**Returns:**

* ([`AcceptedSendResult`](/api/core-operations#agentconnect-core-operations-acceptedsendresult)): An acknowledgement that the Team accepted the event.

**Raises:**

* [`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror): The Agent has not joined, or the Team rejected
  the send. Read `code`.

### `get_history`

<p className="ac-symbol-meta">async</p>
```python
get_history(*, before: Optional[str] = None, limit: int = 50) -> HistoryResult
```

Return one page of this Delivery's Thread history.

The first page is the newest. Messages inside a page run from
oldest to newest. Omit `before` for that newest page. A `before`
id missing from the transcript returns that same page. The result
is empty when this Message has no `thread_id`.

**Parameters:**

* `before` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str)]): Return Messages older than this id. Use `next_before`
  from the previous page.

* `limit` ([`int`](https://docs.python.org/3/library/stdtypes.html#int)): Page size, from 1 to 200. Defaults to 50.

**Returns:**

* ([`HistoryResult`](/api/core-operations#agentconnect-core-operations-historyresult)): One page. Pass `next_before` as `before` when `has_more` is true.

**Raises:**

* [`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror): The Agent has not joined, or is not a participant.

## `DeferredReply`

Handle that finishes one request after `handle` returns.

Obtain it from `Context.defer`, then finish once with `reply`,
`fail`, or `decline`. The Delivery remains leased and counts
toward `max_in_flight`. The lease is renewed until completion,
the request deadline, a disconnect, or revocation by the Team.
If it expires, another running copy may handle the Delivery.

<a id="agentconnect-agent-context-deferredreply-fail"></a>

### `fail`

<p className="ac-symbol-meta">async</p>
```python
fail(
    message: str,
    *,
    code: str = 'handler_failed',
    details: Optional[Mapping[str, JsonValue]] = None,
) -> ReplyResult
```

Fail the request with a message the requester can read.

The Ticket error code is `handler_failed`. This call stores
`message` as the error text. A different `code` is stored under
`details`, and the public code stays `handler_failed`. Put an
application-specific code in `details` as well. An exception
raised from `handle` stores `The handler failed.` instead of
the exception text.

**Parameters:**

* `message` ([`str`](https://docs.python.org/3/library/stdtypes.html#str)): Text the requester can read.

* `code` ([`str`](https://docs.python.org/3/library/stdtypes.html#str)): Extra code stored in `details` when it is not
  `handler_failed`.

* `details` ([`Optional`](https://docs.python.org/3/library/typing.html#typing.Optional)\[[`Mapping`](https://docs.python.org/3/library/collections.abc.html#collections.abc.Mapping)\[[`str`](https://docs.python.org/3/library/stdtypes.html#str), [`JsonValue`](/api/core-base#agentconnect-core-base-jsonvalue)]]): JSON object stored on the error. Omit to store none.

**Returns:**

* ([`ReplyResult`](/api/core-operations#agentconnect-core-operations-replyresult)): The Team acknowledgement for this failed reply.

**Raises:**

* [`RuntimeError`](https://docs.python.org/3/library/exceptions.html#RuntimeError): This handle already finished the Delivery.

* [`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror): The Session is disconnected, the lease expired,
  or the Ticket is already closed.

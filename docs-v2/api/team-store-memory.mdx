
## `MemoryStore`

```python
MemoryStore()
```

Volatile document store backed by dicts in this process.

`insert`, `compare_and_set`, and `apply` are atomic with respect to
other MemoryStore operations. State survives Client disconnects, not
process exit.

Create an empty in-process store.

Inherits from [`Store`](/api/team-store-base#agentconnect-team-store-base-store).

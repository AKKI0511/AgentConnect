## `ApplyResult`

```python
ApplyResult(ok: bool, reason: Optional[str] = None, op_index: Optional[int] = None)
```

Outcome of an atomic batch.

<a id="agentconnect-team-store-ops-applyresult-ok"></a>

### `ok`

```python
ok: bool
```

True after every operation commits; False leaves the store unchanged.

<a id="agentconnect-team-store-ops-applyresult-reason"></a>

### `reason`

```python
reason: Optional[str] = None
```

None on success. Conflicts are `exists` for an existing insert key,
`cas` for a missing or mismatched version, `busy` for an index
cardinality cap, and `limit` for an increment cap.

<a id="agentconnect-team-store-ops-applyresult-op-index"></a>

### `op_index`

```python
op_index: Optional[int] = None
```

Zero-based conflicting operation index.
None when unknown or successful.

## `IncrementIfBelow`

```python
IncrementIfBelow(key: str, limit: int, ttl_seconds: Optional[float] = None)
```

Atomically increment an integer document when it is below `limit`.

A missing document starts at zero. Hitting the cap fails the batch
with `limit`. A write advances its version. TTL follows
[`Store.increment_if_below`](/api/team-store-base#agentconnect-team-store-base-store-increment-if-below); memory ignores the hint.

<a id="agentconnect-team-store-ops-incrementifbelow-key"></a>

### `key`

```python
key: str
```

Integer document key.

<a id="agentconnect-team-store-ops-incrementifbelow-limit"></a>

### `limit`

```python
limit: int
```

Exclusive upper bound for the value before increment.

## `DecrementFloor`

```python
DecrementFloor(key: str, ttl_seconds: Optional[float] = None)
```

Decrement an integer document, not below `0`.

Always writes, creating zero at version 1 if the key is absent, or
advancing the existing version. TTL follows [`Store.increment_if_below`](/api/team-store-base#agentconnect-team-store-base-store-increment-if-below);
memory ignores the hint. This operation cannot conflict on its own.

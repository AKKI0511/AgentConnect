Runtime operation requests and results from the public schema.

These are the JSON bodies for join, send, lease, reply, collect, history,
status, and related calls. A Ticket is the requester's durable record for
one request. An Address is an Agent name, optionally `name@team`. A DID
is the Agent's `did:key` identity.

## `JoinChallenge`

Short-lived challenge used to prove Agent DID control.

A DID is the Agent's `did:key` identity. The Client signs this
challenge with [`issue_identity_proof`](/api/core-identity#agentconnect-core-identity-issue-identity-proof) and sends the JWT as
`identity_proof` on join.

**Attributes:**

* `nonce` (`str`): At least 128 bits of random data in base64url form.

* `audience` (`str`): Exact JWT audience required by the Runtime.

* `expires_at` ([`Timestamp`](/api/core-primitives#agentconnect-core-primitives-timestamp)): Time after which this challenge cannot authenticate a join.

Inherits from [`SchemaModel`](/api/core-base#agentconnect-core-base-schemamodel).

## `JoinRequest`

Input that creates or reconnects a Membership and opens one Instance.

`spec_version` is required on the wire. [`Team.join`](/api/team-runtime#agentconnect-team-runtime-team-join) fills it when you
pass kwargs. `delivery_history="ids"` puts earlier Message ids on each
Delivery instead of Message bodies. Omit it to receive bodies.

**Attributes:**

* `spec_version` ([`SpecVersion`](/api/core-primitives#agentconnect-core-primitives-specversion)): Exact public contract version implemented by the Client.

* `name` ([`AgentName`](/api/core-primitives#agentconnect-core-primitives-agentname)): Requested Agent name, canonicalized by the Runtime.

* `agent_did` ([`AgentDid`](/api/core-primitives#agentconnect-core-primitives-agentdid)): Agent-owned `did:key` proved by `identity_proof`.

* `profile` ([`AgentProfile`](/api/core-profile#agentconnect-core-profile-agentprofile)): Discovery information that replaces the Membership's Profile.

* `instance_id` (`Optional[Uuid]`): Stable id for one running copy. Omit to let the
  Runtime assign one. Re-joining with the same value replaces

* `max_in_flight` (`Optional[JsonInt]`): Maximum active Delivery leases for this Session,
  including deferred replies. Defaults to 1.

* `join_token` (`Optional[str]`): Required by a network Runtime; omitted for trusted
  embedded join.

* `identity_proof` (`Optional[str]`): EdDSA JWT required by a network Runtime.

* `delivery_history` (`Optional[DeliveryHistoryForm]`): How Deliveries carry Thread history. Omit for bodies.

## `RuntimeLimits`

Fixed operational limits a Runtime reports at join.

**Attributes:**

* `max_message_bytes` (`JsonInt`): Maximum UTF-8 JSON bytes of a `send` or `reply`
  body. HTTP applies the same budget to every JSON request body.

* `max_mailbox_depth` (`JsonInt`): Maximum queued plus leased Mailbox items before
  `send` returns `busy`.

* `delivery_history_limit` (`JsonInt`): Maximum earlier Thread Messages included
  in a Delivery `history` window.

* `wait_hold_seconds` (`JsonFloat`): Seconds a `collect="wait"` send may stay open.

* `max_held_waits` (`JsonInt`): Maximum concurrent `collect="wait"` sends one
  Membership may hold. Further waits fail with `wait_limit`.

* `work_lifetime_seconds` (`JsonFloat`): Cutoff stamped on a new request whose send
  omitted `deadline` and that has no request parent to inherit from.

* `max_deadline_seconds` (`JsonFloat`): Farthest a new request deadline may be from
  acceptance.

* `max_open_tickets` (`JsonInt`): Maximum open Tickets one Membership may hold as
  requester. A Ticket is the durable record for one request.

* `replay_horizon_seconds` (`JsonFloat`): Seconds after an obligation ends during
  which an identical retry returns the original result.

* `max_retained_bytes` (`JsonInt`): Maximum UTF-8 JSON bytes of retained Message
  bodies this Runtime keeps.

**Examples:**

```python
result.limits.max_message_bytes
result.limits.replay_horizon_seconds
```

Inherits from [`SchemaModel`](/api/core-base#agentconnect-core-base-schemamodel).

## `RequestSendRequest`

Send a request. Always opens a Ticket.

A Ticket is the requester's durable record for that request. `collect`
is `wait` or `ticket`. `deadline` may be omitted; the Runtime stamps
the effective cutoff on the accepted Message. Fire-and-forget work is
[`EventSendRequest`](/api/core-operations#agentconnect-core-operations-eventsendrequest).

**Attributes:**

* `kind` (`Literal['request']`): Always `request`.

* `collect` ([`CollectMode`](/api/core-primitives#agentconnect-core-primitives-collectmode)): How the sender collects the result. `wait` holds the
  call; `ticket` returns immediately.

* `deadline` (`Optional[Timestamp]`): Future absolute work cutoff. Omit to inherit a request
  parent, or to receive the Runtime work lifetime on a root request.

**Examples:**

```python
RequestSendRequest(
    id=message_id,
    recipient="writer",
    kind="request",
    content={"task": "draft this"},
    collect="ticket",
    deadline="2026-08-18T15:10:00Z",
)
```

Inherits from [`SendBase`](/api/core-operations#agentconnect-core-operations-sendbase).

Result of `status`.

**Attributes:**

* `team_name` ([`TeamName`](/api/core-primitives#agentconnect-core-primitives-teamname)): Canonical Team name.

* `persistence` ([`PersistenceMode`](/api/core-primitives#agentconnect-core-primitives-persistencemode)): Runtime restart guarantee.

## `RuntimeEvent`

One event pushed on the Session event stream.

`type` is open so new event types can be added. A Client must ignore
an unknown type. Defined types include `work_available`, whose `data`
is empty, and `trace`, whose `data` is a [`TraceEvent`](/api/core-operations#agentconnect-core-operations-traceevent).

**Attributes:**

* `type` (`str`): Event type name.

* `data` ([`JsonObject`](/api/core-base#agentconnect-core-base-jsonobject)): Type-specific data.

Inherits from [`SchemaModel`](/api/core-base#agentconnect-core-base-schemamodel).

<a id="agentconnect-core-operations-runtimeevent-type"></a>

### `type`

```python
type: str
```

Required.

* `pattern`: `'^[a-z][a-z0-9_]{0,63}$'`

<a id="agentconnect-core-operations-runtimeevent-data"></a>

### `data`

```python
data: JsonObject
```

Required.

<a id="agentconnect-core-operations-toolerrorresult"></a>

## `ToolErrorResult`

Structured MCP tool result when a Runtime operation fails.

The MCP error flag is set. `error` is the unchanged Runtime
[`ErrorObject`](/api/core-error#agentconnect-core-error-errorobject). Readable text is `code: message`. Malformed arguments
and authentication failures stay MCP-level errors, not this object.

**Attributes:**

* `error` ([`ErrorObject`](/api/core-error#agentconnect-core-error-errorobject)): Runtime failure preserved without reinterpretation.

Inherits from [`SchemaModel`](/api/core-base#agentconnect-core-base-schemamodel).

### `error`

```python
error: ErrorObject
```

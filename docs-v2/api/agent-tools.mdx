Session-bound callables for hosts that do not speak MCP.

`BaseAgent.team_tools()` returns `find`, `ask`, `tell`, `get_result`,
`get_history`, and `get_profiles` bound to this Agent's Session. Results
are JSON dicts. The Team MCP server is the other door, for clients that
speak MCP.

A request (`ask`) opens a Ticket and expects a reply. A notice (`tell`)
does not. `collect="wait"` bounds that one call and may still return an
open TicketView. `collect="ticket"` returns immediately. Ending a wait
does not cancel accepted work. Collect later with `get_result`. Ask and
get\_result return TicketView JSON (`ticket_id`, not `id`).

Callables look up the Session at call time, so `self.team_tools()` is
safe in `__init__` before `join`. The callables fail until a Session
exists. `ask` and `tell` also accept `idempotency_key`. When
`thread_id` is omitted, `ask` outside `handle` mints a Thread. From
`handle`, `ask` inherits the current Thread when `recipient` is the
other party, otherwise starts a new Thread. An omitted `tell`
`thread_id` stays unthreaded outside `handle`; from `handle` it
follows the same inherit-or-start rule as `ask`.

Register an extra callable with [`Tool.from_callable`](/api/agent-tools#agentconnect-agent-tools-tool-from-callable), or construct [`Tool`](/api/agent-tools#agentconnect-agent-tools-tool)
when annotations cannot express the schema.

**Examples:**

After both Agents have joined:

```python
tools = caller.team_tools()
found = await tools.find(query="echo a message")
ticket = await tools.ask(
    recipient=found["matches"][0]["address"],
    content="ping",
)
if ticket["state"] == "completed":
    ticket.get("content")
```

## `Tool`


One function a host may call.

Pass a plain annotated function to `from_callable` to derive the
JSON Schema from the signature and docstring. Construct [`Tool`](/api/agent-tools#agentconnect-agent-tools-tool)

**Attributes:**

* `name` (`str`): Tool name advertised to the host.

* `description` (`str`): Text the host shows for this tool.

* `parameters` (`dict[str, Any]`): JSON Schema object for keyword arguments.

* `handler` (`ToolHandler`): Callable invoked with those keywords.

* `params_model` (`Any`): Optional Pydantic model used to validate arguments.

**Examples:**

```python
from agentconnect.agent import Tool

async def search_docs(query: str) -> str:
    """Search internal docs.

    Args:
        query: The search text.
    """

Tool.from_callable(search_docs)
```

### `from_callable`

```python
from_callable(fn: ToolHandler, *, name: str | None = None, description: str | None = None) -> Tool
```

Build a Tool from an annotated function and its docstring.

Parameter descriptions come from the function's `Args` section.
The first paragraph of the docstring becomes `description` unless
you pass one.

**Parameters:**

* `fn` (`ToolHandler`): Async or sync callable. Each advertised argument needs a
  type annotation other than `Any`. Keyword-only and
  positional-or-keyword arguments are supported.

* `name` (`str | None`): Tool name. Defaults to `fn.__name__`.

* `description` (`str | None`): Tool description. Defaults to the docstring
  summary.

**Returns:**

* ([`Tool`](/api/agent-tools#agentconnect-agent-tools-tool)): A [`Tool`](/api/agent-tools#agentconnect-agent-tools-tool) whose `parameters` schema matches the signature.

**Raises:**

* (`ValueError`): The signature cannot be advertised (`*args`,
  `**kwargs`, positional-only, missing annotation, or
  `Any`).

## `TeamTools`

```python
TeamTools(session_getter: Callable[[], Session])
```

`find`, `ask`, `tell`, `get_result`, `get_history`, and `get_profiles` for one Session.

Iterate the sequence for [`Tool`](/api/agent-tools#agentconnect-agent-tools-tool) objects (name, description, JSON
Schema). Call the methods for JSON results. `ask` and `get_result`
return TicketView JSON. Branch on `state`. An `open` view has
`ticket_id`, not `content`. A completed view has `content`.

Build through `BaseAgent.team_tools()` so the getter works before
`join`.

Bind to a getter so tools can be built before `join`.

**Parameters:**

* `session_getter` (`Callable[[], Session]`): Zero-argument callable that returns the
  connected [`Session`](/api/agent-session#agentconnect-agent-session-session). `BaseAgent.team_tools()` supplies
  this.

### `find`

```python
find(query: str, *, limit: int | None = None) -> dict[str, Any]
```

Search this Team's Directory, excluding this Agent.

Light cards include Address, summary, Skill names, and Profile
tags. Ranked matches are candidates, not proof of suitability.
Call `get_profiles` for full Profiles.

**Parameters:**

* `query` (`str`): Natural-language description of the work.

* `limit` (`int | None`): Maximum matches from 1 to 100. Omit to receive every
  other member, at most 100.

**Returns:**

* (`dict[str, Any]`): JSON with a `matches` list, best first.

**Raises:**

* ([`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror)): The Agent has not joined.

**Examples:**

```python
found = await tools.find(query="someone who can draft a summary")
found["matches"][0]["address"]
```

<a id="agentconnect-agent-tools-teamtools-ask"></a>

`async`

### `ask`

```python
ask(recipient: str, content: Any, *, deadline_seconds: Optional[float] = None, collect: CollectMode = 'wait', thread_id: Optional[str] = None, parent_id: Optional[str] = None, metadata: Optional[Mapping[str, Any]] = None, idempotency_key: Optional[str] = None) -> dict[str, Any]
```

Send a reply-expected request and return TicketView JSON.

`collect="wait"` (default) holds until the Ticket is terminal or
the Runtime wait hold elapses, then returns the current view.
That view may still be `open`. Ending the wait does not cancel
accepted work. `collect="ticket"` returns immediately. Branch on
`state`. Keep `ticket_id` and call `get_result`. Do not send
another `ask` to collect. A completed view has `content`.

Pass `idempotency_key` so a retry reuses the same Ticket. Changed
keyed arguments raise `id_conflict`. When `thread_id` is omitted,
a key selects a stable Thread, a call from `handle` inherits, and
a call outside `handle` starts a new Thread.

**Parameters:**

* `recipient` (`str`): Local name or same-Team qualified Address, for
  example `writer` or `writer@content-squad`.

* `content` (`Any`): The work, as text or JSON.

* `deadline_seconds` (`Optional[float]`): Work cutoff in seconds. Omit to inherit a
  request parent or the Runtime work lifetime. This is not
  how long this call waits.

* `collect` ([`CollectMode`](/api/core-primitives#agentconnect-core-primitives-collectmode)): `"wait"` (default) holds this call. `"ticket"`
  returns immediately. Neither cancels work.

* `thread_id` (`Optional[str]`): Continue this conversation with the same
  recipient. Omit to mint, inherit, or key as described
  above.

* `parent_id` (`Optional[str]`): Message this send answers. From a handler, omit
  to use the current Message.

* `metadata` (`Optional[Mapping[str, Any]]`): Optional JSON object stored on the Message.

* `idempotency_key` (`Optional[str]`): Reuse the same Ticket on retry. Use a new
  key only for new work.

**Returns:**

* (`dict[str, Any]`): TicketView JSON. An `open` view has `ticket_id` and no

* (`dict[str, Any]`): `content`. A completed view has `content`.

**Raises:**

* ([`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror)): The Agent has not joined, `collect` is not
  `wait` or `ticket`, keyed arguments conflict, or the
  Runtime rejected the send. Branch on `code`.

**Examples:**

Wait, then read a completed reply:

```python
ticket = await tools.ask(
    recipient="writer",
    content={"task": "draft this"},
)
if ticket["state"] == "open":
    ticket = await tools.get_result(ticket["ticket_id"])
if ticket["state"] == "completed":
    ticket["content"]
```

### `tell`

```python
tell(recipient: str, content: Any, *, thread_id: Optional[str] = None, parent_id: Optional[str] = None, metadata: Optional[Mapping[str, Any]] = None, idempotency_key: Optional[str] = None) -> dict[str, Any]
```

Send an event. No Ticket is created.

Acceptance means the Runtime queued the event, not that the
recipient finished handling it. Pass `idempotency_key` so a retry
reuses the same Message. Changed keyed arguments raise
`id_conflict`.

**Parameters:**

* `recipient` (`str`): Local name or same-Team qualified Address.

* `content` (`Any`): The notice, as text or JSON.

* `thread_id` (`Optional[str]`): Continue this conversation with a current
  participant. Omit outside `handle` for an unthreaded
  notice. From `handle`, omit to inherit or start a
  Thread the same way as `ask`.

* `parent_id` (`Optional[str]`): Message this send answers. From a handler, omit
  to use the current Message.

* `metadata` (`Optional[Mapping[str, Any]]`): Optional JSON object stored on the Message.

* `idempotency_key` (`Optional[str]`): Reuse the same Message on retry. Use a new
  key only for new work.

**Returns:**

* (`dict[str, Any]`): JSON with `status` `"accepted"` and `thread_id` when the

* (`dict[str, Any]`): event is threaded.

**Raises:**

* ([`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror)): The Agent has not joined, keyed arguments
  conflict, or the Runtime rejected the send.

**Examples:**

```python
await tools.tell(recipient="writer", content={"note": "source changed"})
```

### `get_result`

```python
get_result(ticket_id: str) -> dict[str, Any]
```

Return the current TicketView this Membership opened.

Repeatable. Does not consume the result. If `state` is `open`,
call again with the same `ticket_id`. Do not send another `ask`.

**Parameters:**

* `ticket_id` (`str`): `ticket_id` from `ask`, equal to the request
  Message id.

**Returns:**

* (`dict[str, Any]`): TicketView JSON, which may still be `open`.

**Raises:**

* ([`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror)): The Agent has not joined, or this Membership
  did not open that Ticket.

**Examples:**

```python
ticket = await tools.get_result(ticket["ticket_id"])
```

`async`

### `get_history`

```python
get_history(thread_id: str, *, before: Optional[str] = None, limit: int = 50) -> dict[str, Any]
```

Return one page of retained Thread history as JSON.

The newest page is first; turns inside a page are oldest to
newest. Omit `before` for the newest page. When `has_more` is
true, pass `next_before` as the next `before`. Only a participant
may read the Thread.

**Parameters:**

* `thread_id` (`str`): Conversation id from a TicketView or Message.

* `before` (`Optional[str]`): Return turns older than this id. Prefer
  `next_before` from the previous page.

* `limit` (`int`): Page size from 1 to 200. Defaults to 50.

**Returns:**

* (`dict[str, Any]`): JSON with `messages`, `has_more`, and `next_before` when

* (`dict[str, Any]`): more pages remain.

**Raises:**

* ([`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror)): The Agent has not joined, or is not a
  participant.

**Examples:**

```python
page = await tools.get_history(thread_id)
if page["has_more"]:
    older = await tools.get_history(
        thread_id, before=page["next_before"]
    )
```

### `get_profiles`

```python
get_profiles(addresses: list[str]) -> dict[str, Any]
```

Return selected teammate Profiles by Address.

Duplicate Addresses are read once. A missing member appears as a
per-item error. Other Profiles still return.

**Parameters:**

* `addresses` (`list[str]`): Member Addresses to read, 1 to 20.

**Returns:**

* (`dict[str, Any]`): JSON with an `items` list. Each item is `status` `"ok"` with

* (`dict[str, Any]`): a Profile, or `status` `"error"` with an error object.

**Raises:**

* ([`SessionError`](/api/agent-errors#agentconnect-agent-errors-sessionerror)): The Agent has not joined, `addresses` is
  invalid, or the Session is unauthorized.

**Examples:**

```python
profiles = await tools.get_profiles(["writer", "editor"])
profiles["items"][0]["status"]
```

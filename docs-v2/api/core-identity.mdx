Agent identity, `did:key`, join proofs, and membership attestations.

Every Agent has an Ed25519 key pair and a `did:key` derived from the
public key. The private key stays with the Client. The Runtime stores
the DID and verifies join proofs against it.

`challenge` is a [`JoinChallenge`](/api/core-operations#agentconnect-core-operations-joinchallenge) from the Runtime. The proof is an
EdDSA JWT. A membership attestation is a separate JWT signed by the Team
key. This Runtime mints that token at join and does not verify inbound
attestations.

**Examples:**

Mint a key. `challenge` is a [`JoinChallenge`](/api/core-operations#agentconnect-core-operations-joinchallenge) from
[`Team.join_challenge`](/api/team-runtime#agentconnect-team-runtime-team-join-challenge):

```python
from agentconnect.core.identity import AgentIdentity, issue_identity_proof

identity = AgentIdentity.create_key_based()
proof = issue_identity_proof(identity, challenge)
```

## `AgentIdentity`

```python
AgentIdentity(did: str, public_key: str, private_key: Optional[str] = None, verification_status: VerificationStatus = VerificationStatus.PENDING, created_at: datetime = utc_now(), metadata: Dict = dict())
```

Ed25519 `did:key` identity for one Agent.

A DID is `did:key:...` derived from the public key. The private key
stays with the Client. `create_key_based` mints a new key pair. Pass
the result to [`BaseAgent`](/api/agent-base#agentconnect-agent-base-baseagent) when you already hold the identity, or pass
`identity_path` and the Client loads or creates the file.

**Attributes:**

* `did` (`str`): `did:key` identifier derived from the public key.

* `public_key` (`str`): SubjectPublicKeyInfo PEM.

* `private_key` (`Optional[str]`): PKCS8 PEM, or omitted on a public-only view.

* `verification_status` ([`VerificationStatus`](/api/core-identity#agentconnect-core-identity-verificationstatus)): Local check state.

* `created_at` (`datetime`): When this object was created.

* `metadata` (`Dict`): Extra JSON-friendly fields.

**Examples:**

```python
identity = AgentIdentity.create_key_based()
agent = Researcher(name="researcher", identity=identity)
```

Persist across restarts with a key file:

```python
agent = Researcher(name="researcher", identity_path="researcher.json")
```

<a id="agentconnect-core-identity-issue-identity-proof"></a>

## `issue_identity_proof`

```python
issue_identity_proof(identity: AgentIdentity, challenge: Mapping[str, Any], *, now: Optional[datetime] = None) -> str
```

Return an EdDSA JWT proving control of `identity.did`.

Required claims are `iss`, `aud`, `nonce`, `iat`, and `exp`. `iss`
is the Agent DID. `aud` and `nonce` copy the challenge. `exp` is the
challenge expiry.

**Parameters:**

* `identity` ([`AgentIdentity`](/api/core-identity#agentconnect-core-identity-agentidentity)): Agent key pair. Must include `private_key`.

* `challenge` (`Mapping[str, Any]`): [`JoinChallenge`](/api/core-operations#agentconnect-core-operations-joinchallenge) fields from the Runtime.

* `now` (`Optional[datetime]`): Clock used for `iat`. Defaults to current UTC.

**Returns:**

* (`str`): Compact EdDSA JWT to send as join `identity_proof`.

**Raises:**

* (`ValueError`): The identity has no private key, the challenge is
  invalid, or the challenge has already expired.

**Examples:**

```python
proof = issue_identity_proof(agent.identity, challenge)
```

<a id="agentconnect-core-identity-issue-membership-attestation"></a>

## `issue_membership_attestation`

```python
issue_membership_attestation(team_identity: AgentIdentity, *, agent_did: str, name: str, address: str, team_name: str, now: Optional[datetime] = None, ttl_seconds: int = DEFAULT_ATTESTATION_TTL_SECONDS) -> str
```

Return a Team-signed JWT that this Team vouches for `agent_did`.

Header `typ` is `ac-membership+jwt`. Claims:

* `iss`: Team DID
* `sub`: Agent DID
* `aud`: `agentconnect:<team-name>`
* `name`: Agent name in this Team
* `address`: qualified Address (`name@team`)
* `iat` / `exp`

This Runtime mints that token at join and does not verify inbound
attestations. Store it and present it later at a Team boundary.

**Parameters:**

* `team_identity` ([`AgentIdentity`](/api/core-identity#agentconnect-core-identity-agentidentity)): Team key pair. Must include `private_key`.

* `agent_did` (`str`): Agent `did:key` this Team vouches for.

* `name` (`str`): Agent name in this Team.

* `address` (`str`): Qualified Address in this Team.

* `team_name` (`str`): Team named in the JWT audience.

* `now` (`Optional[datetime]`): Clock used for `iat`. Defaults to current UTC.

* `ttl_seconds` (`int`): Lifetime from `now`. Defaults to 365 days.

**Returns:**

* (`str`): Compact membership-attestation JWT.

**Raises:**

* (`ValueError`): The Team key is missing, or `agent_did` is not Ed25519.

**Examples:**

```python
jwt = issue_membership_attestation(
    team.identity,
    agent_did=agent.agent_did,
    name="writer",
    address="writer@content-squad",
    team_name="content-squad",
)
```

HTTP application for a Team Runtime.

`create_runtime_app(team)` returns an ASGI app that serves Session
routes at `/agentconnect/v1` and Team MCP at `/mcp`. Use it behind
your own server for authenticated or non-loopback serving.
[`Team.serve`](/api/team-runtime#agentconnect-team-runtime-team-serve) and `agentconnect up` bind loopback only.

Session routes require a bearer token except join and join-challenge.
Loopback calls with no `Authorization` header run as the reserved
`operator` Membership only when the HTTP peer is loopback and the
request has no forwarded-client headers, including empty
`X-Forwarded-*` values.

`SessionAuthMiddleware` is used by that app. Call [`create_runtime_app`](/api/team-http#agentconnect-team-http-create-runtime-app)
instead of constructing the middleware yourself.

## `create_runtime_app`

```python
create_runtime_app(team: Team) -> FastAPI
```

non-loopback serving. [`Team.serve`](/api/team-runtime#agentconnect-team-runtime-team-serve) and `agentconnect up` bind
loopback only.

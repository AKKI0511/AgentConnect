Ticket union discriminated on `state`, plus model-facing TicketView.

A Ticket is the requester's durable record for one request Message. Its
id equals that request id. Read completion from `state`: `open`,
`completed`, `failed`, `expired`, or `declined`. MCP `ask` / `get_result`
return [`TicketView`](/api/core-ticket#agentconnect-core-ticket-ticketview); Runtime, HTTP, and Client `ask` return the wire Ticket.

## `TicketBase`

Fields shared by every Ticket state.

Read completion from `state`. A completed Ticket carries `response`;
a failed or expired Ticket carries `error`. Do not treat missing
content as pending, declined, and failed at once.

`trace_id` is the request Message's causal id, retained so
`get_result` can feed `get_trace` after Session replacement.

**Attributes:**

* `id` ([`Uuid`](/api/core-primitives#agentconnect-core-primitives-uuid)): Request Message id.

* `requester` ([`QualifiedAddress`](/api/core-primitives#agentconnect-core-primitives-qualifiedaddress)): Membership that sent the request and owns this Ticket.

* `recipient` ([`QualifiedAddress`](/api/core-primitives#agentconnect-core-primitives-qualifiedaddress)): Membership asked to handle the request.

* `thread_id` (`Optional[Uuid]`): Conversation the request belongs to, when it has one.

* `trace_id` ([`Uuid`](/api/core-primitives#agentconnect-core-primitives-uuid)): Causal id of the request this Ticket records.

* `created_at` ([`Timestamp`](/api/core-primitives#agentconnect-core-primitives-timestamp)): Request acceptance time.

* `updated_at` ([`Timestamp`](/api/core-primitives#agentconnect-core-primitives-timestamp)): Time of the last state transition or late-reply observation.

* `deadline` ([`Timestamp`](/api/core-primitives#agentconnect-core-primitives-timestamp)): Absolute time after which an open Ticket expires.

* `late_reply_count` (`JsonInt`): Distinct replies observed after this Ticket
  became terminal.

Inherits from [`SchemaModel`](/api/core-base#agentconnect-core-base-schemamodel).

## `DeclinedTicket`

Ticket the recipient deliberately declined.

The recipient handled the request and chose not to answer. This is a
terminal, non-failure outcome, distinct from a handler failure and
from a deadline that expired with no handling.

Inherits from [`TicketBase`](/api/core-ticket#agentconnect-core-ticket-ticketbase).

## `ticket_view`

```python
ticket_view(ticket: Ticket) -> TicketView
```

Project a wire Ticket into the model-facing TicketView.

**Parameters:**

* `ticket` ([`Ticket`](/api/core-ticket#agentconnect-core-ticket-ticket)): Wire Ticket returned by Runtime, HTTP, or Client `ask`.

**Returns:**

* ([`TicketView`](/api/core-ticket#agentconnect-core-ticket-ticketview)): The lean view MCP `ask` / `get_result` and Session-bound tools return.

**Examples:**

Branch on `state` after a model-facing collect:

```python
from agentconnect.core.ticket import ticket_view

view = ticket_view(ticket)
if view.state == "completed":
    view.content
```

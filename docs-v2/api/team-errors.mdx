## `TeamError`

```python
TeamError(code: str, message: str, *, details: Optional[dict[str, Any]] = None, retryable: Optional[bool] = None)
```

A failed Team operation.

Read `code` to decide whether to handle or propagate the error.

Common codes are `not_found`, `unauthorized`, `busy`, and
`wait_limit`.

**Examples:**

`team` is started, and `name` is an agent name. Removing a
membership that is already gone is safe. Any other [`TeamError`](/api/team-errors#agentconnect-team-errors-teamerror)
still propagates.

```python
from agentconnect.team import TeamError

try:
    await team.remove_membership(name)
except TeamError as exc:
    if exc.code != "not_found":
        raise
```

## `DirectoryEntry`

Full Directory record for one Membership.

Runtime `get_profile` returns Address, DID, and Profile together.
The Client method is :meth:`~agentconnect.agent.base.BaseAgent.get_entry`.
Model-facing tools return :class:[`GetProfilesResult`](/api/core-directory#agentconnect-core-directory-getprofilesresult) instead.

.. code-block:: python

```
entry = await agent.get_entry("writer")
entry.profile.summary
entry.profile.description
```

Inherits from [`SchemaModel`](/api/core-base#agentconnect-core-base-schemamodel).

## `FindRequest`

Find teammates by describing the work.

Ranked matches are candidates, not proof of suitability. Overlapping
Profiles need `get_profiles`. Reuse cards already read. You may
conclude nobody fits. Compact cards omit description; that text is
on the full Profile.

Inherits from [`SchemaModel`](/api/core-base#agentconnect-core-base-schemamodel).

<a id="agentconnect-core-directory-findrequest-query"></a>

### `query`

```python
query: str
```

Natural-language description of the work. Ranked matches are candidates, not proof that someone is suitable.

Required.

* `min_length`: `1`
* `max_length`: `1000`
* `pattern`: `'\\S'`

<a id="agentconnect-core-directory-findrequest-limit"></a>

### `limit`

```python
limit: Optional[JsonInt] = None
```

Maximum matches from 1 to 100. Omit to receive every other member, at most 100.

Default: `None`.

* `ge`: `1`
* `le`: `100`

<a id="agentconnect-core-directory-findresult"></a>

## `FindResult`

Ordered local Directory search result.

Matches are best-first. The result does not name the embedding
backend or a fallback.

.. code-block:: python

```
found = await agent.find("someone who can draft a summary")
found.matches[0].address
found.matches[0].summary
```

Inherits from [`SchemaModel`](/api/core-base#agentconnect-core-base-schemamodel).

## `GetProfilesRequest`

Read one or more teammate Profiles by Address.

Inherits from [`SchemaModel`](/api/core-base#agentconnect-core-base-schemamodel).

<a id="agentconnect-core-directory-getprofilesrequest-addresses"></a>

### `addresses`

```python

```

Member Addresses to read, 1 to 20. Duplicate requested strings are read once, keeping the first.

Required.

* `min_length`: `1`
* `max_length`: [`MAX_GET_PROFILES`](/api/core-directory#agentconnect-core-directory-max-get-profiles)
